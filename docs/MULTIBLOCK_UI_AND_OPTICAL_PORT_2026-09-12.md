# 多方块显示、砧配方与光学能源移植

本轮处理主控 Jade、JEI 三维装配预览、砧配方缺失、反应堆玻璃面和 JEI 边框，并继续推进激光/光纤/量子转换设备。**列出的八大板块没有全部完成，不能把本轮当作完整 GT6 已移植。**

## 本轮实现

### 主控 Jade

- 所有提供结构检查的现有主控接入共同的 `StructureController` 接口，包括普通大型配方机器和独立控制器。
- 服务端发送成型状态、普通加工进度、可查询的独立储能和储液数据；不把整个机器存档和库存发到客户端。
- 普通机器原来的 Jade 流体循环会遗漏同索引的输出槽，本轮同时修正。
- 七类旧主控的结构验证改用共同的坐标定义；遇到未加载区块返回不满足，不强制加载区块。

### JEI 装配页

- 主控增加装配分类关联，可在其 R/U 查询中找到装配页。
- 使用真实方块模型的三维预览，支持左右旋转、上下选层和恢复全层。保留部件需求物品槽，悬停下方说明查看要求。
- 装配页缩为 176×174，替换原来的高页面和彩色平面格子。
- 补充焦炉、大型坩埚、大型发电机、低温蒸馏塔、蒸馏塔、大型蒸汽轮机、旧聚变主控的当前结构预览，并与其验证共用 `ControllerStructureLayouts`。
- **这些旧主控仍有未还原的行为；对应预览说明明确标注。聚变目前仍非原版 19×19 结构，也没有完整启动和生产流程。**
- 普通加工 JEI 不再绘制机器 GUI 外侧 3 像素边框，槽位坐标保留。
- 参考 GTM 的独立装配分类和三维展示方式；没有复制 GTM 代码、资源或引入其 UI 库。

### 砧

- 修正配方冲突判断：重复输入必须累计数量，流体同时比较 NBT；砧的空工作区要求参与冲突判断。
- 原来的判断会把不同的锭组合误判为重复，导致配方在注册时丢失。
- 保留 GT6 的“两锭 → 双锭 → 板”两步链路，压板保留 90% 废料概率，并要求另一工作区为空。
- 不再只枚举 17 种材料。从原版材料工厂继承关系导入 281 条可供自体锻造规则使用的金属定义，再按实际注册材料与形态筛选。
- 排除原版注明可燃、涂层或特殊锻造目标的声明；特殊材料转换仍需独立补齐，281 不是新增配方条数或全材料完成率。
- 增补金属块粒（chunkGt）到小板及废料的原版规则。

### 反应堆外观

- 核心的染色底层由 solid 改为 cutout，允许原版 side1 纹理的透明像素透视。
- 核心方块取消完整遮挡，防止透过玻璃时相邻方块的面被剔除。
- 2×2 核心改用原版自己的 12 张纹理，不再借用 1×1；铅色保留。
- 没有因此完成中子、燃料棒内部渲染、冷却剂和辐射系统重做。

### 光学能源

- 5 个电力 CO2 激光器：EU → LU，额定 2:1。
- 5 个 Flux 激光器：RF/FE → LU，额定 8:1；FE 与 GT RF 使用同一个储能缓冲。
- 5 个激光吸收器：LU → EU，额定 2:1。
- 5 个量子激励器：LU → QU，额定 2:1。
- 比例、额定输入/输出和输入面依据 GT6 的对应注册定义；光学转换器采用原版未使用能量按刻耗散的行为。
- 原来量子激励器的 EV–UV 注册名保留，显示名称修正为原版 T1–T5，避免旧存档注册名变动。
- 共用六向扳手和朝向预览；潜行空手右键开关；停机状态及缓冲支持存档。
- 光纤接入 LU 包传输，支持分支、环路去重、模拟注入、断线即时失效。迭代遍历上限 4096，不加载远端区块。
- 光纤剪线钳操作使用已有共用面选择系统；物品预览南北连接，世界模型随连接变化。
- 恢复对应 GT6 底图、活动覆盖层和材料染色。可重生成脚本：`tools/restore_laser_models.py`。
- 按原版图样补入 15 个制造配方：CO2 激光器、Flux 激光器和量子激励器各五级。使用现有的代表材料物品；等价材料替代和上游生产链尚未全部补齐。生成脚本：`tools/generate_optical_recipes.py`。
- 21 个光学方块加入镐采掘标签；转换器拆下保留停机及缓冲状态，光纤有正常方块掉落。
- 自动连接回归复现了方块实体初始连接缓存落后于世界状态的问题，光纤路由改为读取当前位置的实际方块状态。
- **尚未包括原版全部模式、过载爆炸、ZPM、完整制造配方及上游部件生产链，不计为高科技系统全部完成。**

### 材料编号

- Graphene 恢复为原版 9175，保留原有名字。
- 移植新增染料使用 9500–9515，移植的 Superconductor 使用 9516，避开原版木材和陨铁合金编号。
- 注册器拒绝重复数字 ID，替代原来静默覆盖。生成源及生成脚本同步修改。
- 游戏物品注册名没有因此改名。旧数据若只保存了已经冲突的裸数字 ID，本轮没有尝试猜测其原本材料；历史误覆盖不能靠编号表自动反推。

## 建议游戏内验收

1. 对准多方块主控看 Jade；分别检查缺块、成型和加工中状态，检查有进出液体时是否都显示。
2. 在 JEI 对主控按 R/U，选择装配分类，点 `<`/`>` 旋转、`-`/`+` 选层、`All` 恢复。按预览搭一台，拆一个部件观察失效。
3. 看普通机器 JEI 顶部、底部和左右边缘，确认外侧 GUI 边框消失且槽位没有错位。
4. 铁、铜、镍等各试两锭合双锭，再把双锭放到一侧、另一侧空着锤成板；检查数量、废料和工件显示。
5. 放置 1×1、2×2 反应堆核心，从玻璃两侧看后方方块，检查透明区域、玻璃纹理和铅色。
6. CO2 激光器正面接光纤，接到吸收器或量子激励器背面；匹配输入功率，测试断线、剪线钳断开、停机。额定 EU/LU 能源不是 JEI 的通用 GU。
7. 在 JEI 查询上述三组光学设备的制造配方；测试镐拆卸、停机后拆下再放置，以及已有存档中光纤自动连接的表现。

客户端 GPU 显示尚未人工验收，自动化通过不代表所有朝向和动画已经验证。
