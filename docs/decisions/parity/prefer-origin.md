# 原版优先

以原版 MC 或原版模组的物品、流体或方块替代 GT 自有实现的条目。

| 内容 | 差异 | 原因 |
| --- | --- | --- |
| 木梁 | `beam_*` 改用去皮原木，配方随之替换；NeoForge 为已列木种保留旧 ID 别名。 | 适配现代 MC 木材体系。 |
| 世界水 | 海洋、河流与热泉水改用原版水；不再注册 GT 水体，也不再向 `minecraft:water` 追加 GT 流体。 | 按奥卡姆剃刀使用原版水，避免整块替换与地图模组不贴合。 |
| 原版 MC 等价物 | 部分 GT 锭、宝石、储存块等优先用 MC 物品；重复项隐藏但保留注册。 | 减少重复展示，保留旧物品可用性。 |
| 蜂蜜瓶 | 删除 `gt6ce:honey` 注册、模型和专用贴图；配方、战利品、三明治和流体装瓶统一使用 MC 蜂蜜瓶，每瓶保持 250 mB 蜂蜜，饮用及空瓶采用 MC 行为。旧物品 ID 不再保留。 | 现代 MC 已有蜂蜜瓶，按 [#317](https://github.com/GregTech6CE/GregTech6/issues/317) 统一为原版物品。 |
| 羊肉物品 | 删除 `gt6ce:mutton`、`gt6ce:grilled_mutton`，改用 MC 生熟羊肉并接回加工链。 | 现代 MC 已有羊肉，不再重复注册。 |
