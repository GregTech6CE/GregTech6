# 世界生成

与 GT6 原版相比，本端在世界生成与矿物生成上的处理差异。

| 内容 | 差异 | 原因 |
| --- | --- | --- |
| 下界矿物生成 | 下界金矿、远古残骸独立开关，默认开启，不随禁用普通 MC 矿石一起关闭。 | 保留现代 MC 下界资源。 |
| 下界基岩矿 | 保留 `glowstone`、`netherquartz`、`ancientdebris`、`efrine`、`firestone` 五种；`voidquartz`、`gloomstone` 停注，灵魂沙散矿的 Gloomstone 分支改为空。 | 停注材料后只恢复仍有独立来源的绿晶与火石，其余下界基岩矿不再生成。 |
| DominicanAmber 接触矿 | 删除 `Coal`/`Lignite`/`Oilshale` 与 `Stone` 接触面的 `AmberDominican` 条目及 SHROOM 群系规则；普通 `Amber` 保留。 | 对应材料停注，见[材料移除](material-removal.md)。 |
| 装饰石生成 | 默认禁用 MC 花岗岩、闪长岩、安山岩矿团，可用 `DisableVanillaDecorativeStone` 调整。 | 避免与 GT 地层生成重复。 |
| 地表散落特殊石子 | 移除 GT6 `WorldgenRocks` 中 1/12 概率的 `MeteoricIron` 粗矿/碎石分支，保留 1/2 空与 1/2 燧石。 | `MeteoricIron` 及其陨钢材料链已停注，见[材料移除](material-removal.md)。 |
| 岩层与矿物 | 主世界从建造下限到各列地表按地质区生成连续岩层，深层包含深板岩、凝灰岩和 GT 硬岩。接触矿按上下或侧向岩性生成，交界小宝石默认每百格判定一次。沉积区保留无烟煤、褐煤薄层。 | 新区块与旧区块在交界处可能出现不同的层序。 |
| 普通矿脉 | 主世界岩层和大矿脉可同时生成。区域内安排保底候选，其余位置按权重抽取。默认 384 格的大区分四个子区，每个子区各安排一处铬铁矿和钛矿候选。附属矿脉也参与规划和抽签。 | 洞穴、海底高度和可替换的宿主决定最后落下的矿块。附属可用 [API 1.11 高度声明](../../ADDON_API.zh-CN.md#附属矿物生成api-111) 指定现代 Y 坐标。 |
| 散矿与矿源 | 主世界恢复石灰岩、板岩和红花岗岩等宿主矿源，深层凝灰岩也可生成明矾石。末地铜、黄铜矿、锡和锡石的散矿在 Y=48～72 生成。 | 为现代主世界深层和末地岛屿补充可采矿源。 |
| 地表指示物 | 岩层石子沿用对应岩石纹理。矿物指示石子与普通石子共用六种造型、四个朝向，以一像素宽的矿物色条纹区分。基岩矿粗矿使用粗矿块纹理。新石子记录外观，旧石子继续读取已有物品和材料；旧数据无法区分的同名岩层和矿物按岩层显示。 | 玩家可从地表识别下方矿物。深水中可放置含水指示石；基岩矿放不下指示花时尝试放置粗矿。 |
| 基岩矿与流体泉 | 基岩矿按种子、维度、区块及矿种独立判定，地层有效矿源决定主世界浅层和深层修正。流体泉与矿床按实际占用互斥，保留钻头位置和已存在的方块实体。 | `worldgen.bedrock` 的 `DensityPercent`、`DisabledOres`、`DisabledDepths` 和 `ChanceOverrides` 影响新生成的自然矿床。下界沿用原始分母，JEI 和 EMI 展示当前服务器启用的矿源。 |
