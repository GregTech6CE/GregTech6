# 长期决策

本目录记录影响后续开发的长期系统架构设计、跨平台边界、原版特性差异与重要技术取舍（例如模块分层契约、存档/身份兼容策略、公开 API 演化方案及核心子系统设计）。日常开发进度、一次性临时计划、排查流水账和普通修复不需要保留在此。

编写或查阅决策前请先理解[现有架构](../architecture/README.md)。若确需为新主题建立设计或取舍记录，可按子专题组织或复制[模板](TEMPLATE.md)按主题命名。文档状态须明确区分“提议 / 接受 / 废止 / 被替代”，未实施的设计规划不得写作当前已生效能力。

当后续决定发生变化时保留必要背景并链接新决策；对外生效的新规范或包职责仍需同步更新到对应架构与开发文档。跨模组兼容测试证据与联动结论归入 [integration](../integration/README.md)。

## 目录

- [材料系统设计](material-system/README.md)：按目录安装、属性形态、物品成分、回收、分解与公共发布视图六大子域整理的当前系统架构及关联规划。
- [跨平台决策与差异](platform/README.md)：Forge（1.20.1）与 NeoForge（1.21.1）之间长期保留的实现取舍与行为边界台账。
- [与原版的特性差异](parity/README.md)：按类别拆分的有意偏离原版 GT6 处理台账，供回归对照与验收。
- [决策模板](TEMPLATE.md)：新增单主题决策条目时从这里复制。
