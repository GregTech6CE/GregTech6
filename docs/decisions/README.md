# 长期决策

本目录解释影响未来开发的重要取舍，例如包边界调整、存档格式迁移、公开 API 策略或跨版本实现方案。日常进度、临时计划和普通修复不需要决策文档。

先读[现有架构](../architecture/README.md)，确有长期选择需要保存时复制[模板](TEMPLATE.md)，命名 `NNNN-<topic>.md`。编号递增，状态使用“提议 / 接受 / 废止 / 被替代”；提议不是已实施事实。

决定改变时保留原背景，标明新决定链接；最终使用方式仍须同步架构/开发指南，不能只留在决策历史里。证据放 [integration](../integration/README.md)，部署结果放 [operations](../operations/README.md)。
