# 长期决策

本目录记录影响后续开发的长期系统架构设计、跨平台边界、原版特性差异与重要技术取舍（例如模块分层契约、存档/身份兼容策略、公开 API 演化方案及核心子系统设计）。

新增设计或取舍记录时，可按子专题组织或复制[决策模板](TEMPLATE.md)按主题命名，并明确标注“提议 / 接受 / 废止 / 被替代”状态，将规划与已生效能力区分开。后续决定发生变化时保留必要背景并链接新决策，同时更新对应的架构与开发文档。

## 目录

- [材料系统设计](material-system/README.md)：按目录安装、属性形态、物品成分、回收、分解与公共发布视图六大子域整理的当前系统架构及关联规划。
- [跨平台决策与差异](platform/README.md)：Forge（1.20.1）与 NeoForge（1.21.1）之间长期保留的实现取舍与行为边界台账。
- [与原版的特性差异](parity/README.md)：按类别拆分的有意偏离原版 GT6 处理台账，供回归对照与验收。
- [决策模板](TEMPLATE.md)：新增单主题决策条目时从这里复制。
