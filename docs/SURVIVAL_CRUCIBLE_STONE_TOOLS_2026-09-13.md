# 生存炼铁、制造、岩层与工具续批（2026-09-13）

## 本轮完成

- 新增 138 条制造／烧制／回收配方：37 条坩埚相关、75 条燃烧室、26 条普通及强化蒸汽锅炉。使用材料标签和有损耗的工具合成。来源为 GT6 Loader_MultiTileEntities；黏土坩埚来自 MultiItemRandomTools。逐项来源见 smeltery-survival-recipes.json。
- 新增 81 条岩石配方：27 类岩石的圆石烧石头、石头烧光滑石、四石头制四石砖。
- 注册 6,503 条岩石加工、砧上碎石、毛坯工具头磨制配方。数量包含材料变体，不代表新增 6,503 种功能。石头可碎成圆石，圆石可粉碎成岩石碎块；纯岩石方块可撕碎为九份粉。钢筋砖、红石砖暂未纳入此批回收，避免丢失额外成分。
- 铝土矿、煤、褐煤、盐、岩盐、油页岩、石膏和石英等整块矿层增加拆成两份原矿的机器入口，再接既有矿处理链。
- 砧增加岩石碎块 → 九份小撮粉；工具增加现有毛坯工具头 → 对应成品工具头的磨制入口，与已有铸模及工具组装衔接。

## 坩埚修复

原逻辑升温时把原材料表原样放回，完全没有执行材料已定义的熔炼目标。本轮使其执行 targetSmelting 和数量比例；也处理已处于高温的存档内容。煤／木炭在 1700 K 时，每份产生半单位碳，焦煤按其原有定义产生一单位碳。

新增原版 MT 中 42 条显式反应，供坩埚和 JEI 共用。示例：

- 5 单位赤铁矿 + 1 单位碳 + 1 单位方解石 → 2 单位铁。
- 14 单位磁铁矿 + 3 单位碳 → 6 单位铁。
- 3 单位二氧化硅 + 1 单位碳 → 1 单位硅。

反应要求达到产物熔点，至多一种原料仍为固态，每 tick 选择产量最多的一条反应。助熔剂和还原剂不计入产物数量。既有普通合金的组成配方保留，产物按组成的 divider 计算，修复原来直接把全部输入量相加的错误。

原矿和普通矿石投入坩埚时使用原材料的粉碎目标和矿石倍率。铁原矿对应三单位赤铁矿，不能绕过还原直接当成纯铁。原矿储存块／16 格箱／64 格箱分别按 9／16／64 份计。原版 Minecraft 铁、铜、金原矿及对应普通／深层矿石也接入此路径。

## JEI 与掉落

- unit 作为信息显示保留，通过不可见检索别名关联同材料实体物品。普通铁锭的 U/R 查询可以检索包含 unit 铁的说明配方。此关联仅用于 JEI 搜索，不放宽机器实际配方匹配。
- 普通 OreBlock 无精准采集时掉一份对应原矿；时运为 1 到等级+1 份；精准采集保留矿石及宿主岩层 NBT。小型矿石和基岩矿石仍使用各自分支。
- 修复原矿注册条件漏掉 GENERATE_ORE_PROCESSING，原来铁等材料缺少原矿物品。
- 将世界生成的矿石标记从方块注册阶段提前到材料初始化阶段，避免先注册矿石方块、却漏注册对应原矿物品。
- 从 StoneType 声明补岩石标记，修复黑／红花岗岩作为复合材料导入后不生成岩石碎块的问题。

## 建议进游戏依次测试

1. 普通镐挖铁矿，看是否掉原矿；再测试时运和精准采集。小矿石和基岩矿应保留原规则。
2. 普通铁锭按 U/R，查坩埚 unit 铁说明是否出现。
3. JEI 查黏土坩埚的成型、烧制；查青铜坩埚、固体／液体／流化床燃烧室及普通／强化锅炉。
4. 用耐温足够的坩埚把两份木炭加热到 1700 K，得到一单位碳。按 JEI 比例投入赤铁矿、碳、方解石并加热到铁熔点，检查产量。石坩埚耐温不足，不能用来验收炼铁。
5. 黑色花岗岩石头 → 圆石 → 岩石碎块 → 砧上粉；石头直接进入撕碎机检查九份粉。
6. 铝土矿整块进粉碎机／锤式机器，检查两份原矿及后续处理。
7. 铸造毛坯镐头 → 磨制 → 与手柄组装工具。

## 尚未完成，不能据此称完整移植

- 本轮机器制造覆盖燃烧室和锅炉，不是所有普通机器、高科技机器的制造全集。
- 砧完整热锻、涂层、异材锻造、修理及全部工具的手工制造链仍须继续逐项对照；本轮工具补的是毛坯磨制，并非所有工具配方已齐。
- Umber、Livingrock、Holystone、Betweenstone 坩埚缺少可用对应石材，未编造替代原料。清单中陶瓷坩埚的“无字面合成图案”由单独黏土烧制链覆盖。
- 空气参与的炼钢反应、任意等价材料组合，以及未声明 ALLOY 的特殊反应尚未全部并入新反应目录。
- 整块矿层的机器拆解是移植版新增生存入口，基于原版两份原矿掉落量；不代表 BlockRockOres 所有时运行为已还原。
- 没有重建 JAR。本轮用于 IDEA runClient 验收；旧 build/libs 中的 JAR 不包含本轮修改。
