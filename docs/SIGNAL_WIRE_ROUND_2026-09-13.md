# 红石信号线移植轮次（2026-09-13）

## 本轮范围

补上上一轮覆盖板所缺少的原版信号线系统。新增红合金、信素、流明的裸线与绝缘线，共六种可放置方块；没有把这些材料注册成 EU 电线。

原版核对位置：`gregtech/loaders/b/Loader_MultiTileEntities.java` 的 27000/27006、27050/27056、27500/27506，以及 `MultiTileEntityWireRedstone`、`MultiTileEntityWireRedstoneInsulated`、`ITileEntityRedstoneWire`。本轮未复制 GTM 代码。

## 可使用的功能

- 六面信号连接，剪线钳使用现有统一选面、预览与双端连接逻辑；与电力线、激光线分属不同连接类型。
- 放置时连接贴附面，并连接相邻信号线与可识别的红石元件；其余端口可手动打开。
- 沿用原版 `Integer.MAX_VALUE` 精度及整数损耗：红合金/流明每约 16 格衰减一级，信素每约 64 格。混合裸线、绝缘线和材料按每段各自损耗传输。
- 支持弱、强红石输出；不向接收信号的面回送。向红石粉或导电实心方块输出时降低一级；比较器按原版向下取整，和普通输出的向上取整不同。
- 螺丝刀设置内置信号源 0–15，潜行时递减；模式保存到 NBT。通用扩展器也能访问模式和进度接口。
- 流明裸线按信号强度发光，流明绝缘线不发世界光。无源读档时会清除旧方块状态中的发光值。
- 共享管线动态模型：物品预览南北延伸、世界六面连接、裸线与粗绝缘线衔接、材质染色、原版绝缘层贴图。客户端实际画面仍需 runClient 验收。
- 三条拉丝机配方：一锭得到两根裸线，16 GU/t、16 ticks；六条覆膜机配方：每种裸线加一橡胶板或四橡胶箔得到绝缘线，16 GU/t、16 ticks。
- 能量显示覆盖板、机器状态显示覆盖板、红石导入覆盖板、红石导出覆盖板四个配方恢复使用原版流明线/红合金线，撤掉同材质板的临时替代。

## 网络实现说明

在服务端对已加载的连通分量每 tick 求解一次，由外部信号源和内置模式重新计算最大有效信号，避免无源环路保留历史信号。先发布整个分量的结果，再通知相邻红石元件。不会强制加载区块，也不使用持有世界或方块实体的静态网络缓存。

这部分采用适配 1.20.1 的网络求解方式；超大规模线路的运行性能尚未进行实机压力测试。

## 建议集中实测

1. 创造栏“导线”找到三种材料的裸线和绝缘线，检查物品预览与放置后颜色。接一段裸线、一段绝缘线，观察细粗衔接。
2. 用拉杆连接红合金线，再用剪线钳打开另一端接红石灯。关掉拉杆后灯应熄灭；可把线路围成环再试。
3. 不接外部信号，用螺丝刀把流明裸线设成 1、8、15，观察亮度与输出。潜行螺丝刀递减，设回 0 熄灭；退出重进后模式保留。
4. 在 JEI 检查三种线的拉丝机与覆膜机配方，以及上述四种覆盖板配方。
