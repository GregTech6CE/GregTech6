# 执行记录

本目录收录实际执行后、可提交且已脱敏的构建交付/发布/实例更新记录。流程见[操作指南](../README.md)，新记录从[模板](TEMPLATE.md)复制。

命名为 `YYYY-MM-DD-<platform>-<topic>.md`，同日多次增加后缀；写明日期时区。不要为只改文档或普通开发编译强制生成记录。私有参数和原始日志放根目录 `work/`，正式记录不能写入令牌、账号、私有地址、存档数据或完整机器路径。

新增记录后在此添加相对链接，保持可导航；完成状态必须对应实际执行，不用模板填空制造成功结论。
