# 岩层与矿物生成

## 岩层

`StoneLayerField` 先在水平面上划分 384 格的网格。每格的地质中心落在中间一半范围。每个方块柱的水平坐标分别按尺度 112、192 的噪声偏移最多 20 格。相邻九个中心按 `dx² + dz² + clamp(Y − 32, −320, 320) × dip` 评分，分数最低者决定火成、沉积或变质地质区。`dip` 由种子取 −84 至 84，因此同一方块柱可随深度进入相邻地质区。

层带在变换后的高度上每 12 格取样。竖向伸缩范围为 0.88～1.12，尺度 112 和 40 的两项噪声分别贡献至多 18 和 5 格位移。层带低于 −22 时使用深层岩石集合，限浅层的岩石从实际 Y=−7 开始。沉积区的无烟煤和褐煤沿两个相距 8 格的层位分布，各自厚度为变换高度的 1.5 格。

每个区块多采样三格岩性边界。六个方向遇到不同岩性时，`StratumOreRules` 按垂直或侧向接触表选矿，接触带深度为两格。只有可替换方块才落矿。交界小宝石概率由服务器配置控制。

## 矿源与矿脉

`OreSourceCatalog` 合并内置定义与附属声明。游戏生成、定位、配方查看器和离线采样读取同一目录。主世界基岩矿从普通矿脉的上层、下层主矿派生。显式例外指定旧版矿床名、指示花和稀有度，也涵盖只在基岩出现的矿物。无覆盖值时，概率分母取 `max(8000, 1600000 / 最大主矿权重)`。浅层来源把分母乘 5/4，深层来源乘 3/4，下界使用自己的五个矿种。

`OreVeinLayout` 以 48 格为一格，每个保底区至少 8×8 格。铬铁矿和钛矿在每个象限各有一个候选。其余保底槽按种子排列，空余槽可再作权重抽签。主世界附属矿先占内置网格的空槽，放不下的进入同算法的额外网格。地形决定最后的落点。矿脉半径最多 34 格，空余槽以 1/8 概率参加额外抽签。浅层保底矿若缺少合适岩体，可在 Y=16 与原区间下限之间寻找低海拔岩体，向下搜索最多 28 格。其他维度的权重池含 243 份空权重。

| 形态 | 方块分布 |
| --- | --- |
| `VEINED` | 两条起伏、错位的矿带。 |
| `LAYERED` | 沿层面展开的薄矿床。 |
| `DIKE` | 较高、横向较窄的岩墙。 |
| `CLUSTER` | 两团有高度差的矿体。 |

普通矿与散矿仅写当前区块。基岩矿指示物使用独立于矿体的随机序列。目标区块重放周边矿床的散落坐标，只放入本区块中的指示花或石子。主世界矿物的生物群系修改器 `gt6ce:gt_overworld_ores` 先放置 `gt6ce:gt_coltan`，再放置普通基岩矿。

## 服务器配置

设置在 `GT6CE/common.toml`。概率、矿种和地质配置作用于随后生成的区块。

| 键 | 默认值与作用 |
| --- | --- |
| `worldgen.geology` | 开启岩层、普通矿脉、散矿与钶钽矿区。 |
| `worldgen.deposits` | 默认开启黏土、泥炭、磁铁矿砂等露天矿坑。 |
| `worldgen.fluid_springs`、`worldgen.fluid_springs_probability` | 默认启用流体泉，基础概率分母为 100，再按泉的种类调整。 |
| `worldgen.surface_rocks` | 开启普通地表石子和下界散落物。矿物指示石跟随其矿源开关。 |
| `worldgen.bedrock_ores` | 开启自然基岩矿及其指示物，也控制地牢和钶钽矿区的基岩核心。 |
| `worldgen.geology_settings.BoundaryGemProbability` | 默认分母 100，范围 1～1,000,000。 |
| `worldgen.bedrock.DensityPercent` | 默认 100，范围 0～400。0 关闭随机自然基岩矿。 |
| `worldgen.bedrock.DisabledOres`、`worldgen.bedrock.DisabledDepths` | 默认空。前者按矿床名或材料名禁用，支持 `*`。后者接受 `shallow`、`deep`、`neutral`。 |
| `worldgen.bedrock.ChanceOverrides` | 默认空。按材料或矿床名指定深度修正后的分母，例如 `gold_b=16000`，随后应用密度百分比。 |

定位指令、真实存档扫描和种子对照的用法见[世界生成工具](../../tools/worldgen/README.md)。
