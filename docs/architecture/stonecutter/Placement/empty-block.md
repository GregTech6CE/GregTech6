# 空块

## 子原因

两侧都没有内容的空块，通常来自“先加分支、后删内容”的中间状态。它不承载任何版本差异，也不属于平台 API 例外。

注意边界：只有两侧都为空才是空块。一侧有语句、另一侧为空的 `//?` 是单侧分支，删除前必须确认该语句在另一版本执行是否等价（初始值、副作用、调用时机）；不能按空块处理。

## 例子

### 修复前

```java
//? if >=1.21.1 {
//?} else {
//?}
import gregtech.api.material.MaterialTextureSet;
```

### 修复后

```java
import gregtech.api.material.MaterialTextureSet;
```

### 为什么这么修复

两侧都没有语句，删除后编译结果和运行时行为都不变，只减少一个 `//?`。

### 其他可能的修复方式

- 保留空块作为占位。后续编辑容易把它误判为有意差异。
- 用空块承载注释。注释不是版本逻辑；需要说明时写在类或字段上。
