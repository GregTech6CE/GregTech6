# JEI 操作、蒸馏塔热输入与 ZPM 放电续批

本批继续处理实际交互与高科技能源链。不能把本批记成高科技系统或全模组移植完成。

## JEI

- 普通机器配方页恢复 GUI 底部的三像素；顶部和左右仍按要求裁剪，物品槽坐标不变。
- 多方块预览支持左键拖动旋转、右键拖动平移、滚轮缩放。
- `<` / `>` 保留按 90 度旋转；`-` / `+` 选择层；`All` 恢复全部层；`R` 按钮复位视角。
- 输入接入当前 JEI 的 `IJeiGuiEventListener`，在预览区域内消费事件；不通过全局鼠标轮询抢占物品槽操作。
- 缩放范围 0.25–4 倍，俯仰和平移有边界；模型绘制限制在预览区域，避免放大后盖住物品槽、按钮或别的配方。
- 相机状态的自动化测试不等于实际鼠标与 GPU 验收，客户端还需实测。

## 蒸馏塔 HU 输入

原问题：旧蒸馏塔只检查热传导部件是否摆对，没有建立部件到主控的能源绑定。外部设备向底部传导部件输送 HU，无法送入主控加工缓冲。

现在蒸馏塔复用大型配方机器的部件绑定与加工执行：

- 底部 3×3 热传导部件接入 HU 输入；额定 512，最小 1，最大 1024，依据原版主控 17101。
- 塔体最下面一层提供物品/流体 IO，上面各层仅提供流体输出；塔体不接受 HU。
- 成型后绑定，缺块立即释放；修复后重新绑定。不会把主控库存或能量复制进结构部件。
- 旧的 40 tick 结构缓存不再用于该塔，避免拆掉结构后旧接口继续输送。

这次没有宣称完整还原蒸馏塔按馏分分别向背面各高度自动排液的全部行为。

原版依据：`gregtech/tileentity/multiblocks/MultiTileEntityDistillationTower.java` 与 `gregtech/loaders/b/Loader_MultiTileEntities.java` 的 17101、18101、18102 定义。

## ZPM

原版定义只有 QU 放电器（11170）和 EU 放电器（11171），不是三级性能机器。保持原有 basic/advanced/elite 注册 ID，分别接入 QU、EU、QU 旧版别名；旧版别名不提供更高输出。

- 新增可放置零点模块，容量 2,000,000,000,000 QU，默认空电，不能重新充电。
- 创造模式提供满电模块用于验收。满电模块暂未接入原版世界遗物获取路线，不添加普通合成充满能源的捷径。
- 放电器单槽仅接收一个 ZPM；手持模块右键放入，空手右键取出，潜行空手右键开关。
- 前面每 tick 最多输出一个 131072 的能源包。QU 版本输出 QU，EU 版本以 1:1 转换为 EU；外部能源不能给 ZPM 反向充电。
- 模块每秒分批向放电器缓冲放电，输出未连接或停机时保持总能量；实际被接收的输出才扣除缓冲。
- 模块自身的电量、放电器库存/缓冲/开关支持存档；拆下放电器将这些内容保存于掉落方块 NBT，不再额外弹出同一模块。
- 支持物品管/漏斗通过物品能力接口装卸；六向扳手沿用共用工具逻辑。
- 拆除后，即使外部仍缓存旧物品接口，也拒绝继续插入或取出，避免旧接口与整机掉落 NBT 重复提取模块。
- 恢复原版 ZPM 两段模型、QU/EU 放电器底图与覆盖层，保留 Osmiridium 染色和装入模块的背面指示。
- 两种放电器的合成采用原版图样及当前已注册的代表材料；尚非全部等价材料替代。

资源和配方生成入口：`python -m tools.restore_zpm_models`。脚本合并语言文件，保留 Jade 配置翻译；生成后执行 `python -m unittest tools.tests.test_jade_translations`。

原版依据：`gregtech/tileentity/batteries/qu/MultiTileEntityZPM.java`、`gregtech/tileentity/energy/storage/MultiTileEntityZPMDechargerQU.java`、`MultiTileEntityZPMDechargerEU.java`、`gregapi/tileentity/energy/TileEntityBase10EnergyBatBox.java` 及注册 14999 / 11170 / 11171。

## 集中实测顺序

1. 普通机器 JEI 查看底边；打开多方块装配页，测试拖动、滚轮、切层、复位和离开页面后再打开。
2. 按装配页搭蒸馏塔，底下九个热传导部件中任选一个接 HU；放入有效配方原料，确认进度和产物。拆一个塔体方块后确认立即停止接收，再补回。
3. 在机器创造栏拿到满电 ZPM，与空电模块的提示区分。先放下再拆回，确认电量不变。
4. 装入 QU/EU 放电器，正面接匹配容量的接收设备。测试开关、断开输出、取出模块、整机拆卸、重新放置和退出重进。
5. 测试漏斗/物品管插入普通物品被拒绝，插入多个模块时只放入一个；检查模块和机器缓冲之和没有凭空增加。
