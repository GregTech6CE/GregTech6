# 第五十批：60 种材料脚手架、生存配方与地牢材质

## GT6 原文与本轮实现

`Loader_MultiTileEntities.java:147` 的 metalset 为每一种材料注册脚手架：ID=8400+aID，硬度固定 5，抗爆沿用材料系列，堆叠上限 64，配方 `TPT / SdS`（螺丝、板、杆、螺丝刀）。本批复用已核对原版的 60 行 GTStorageMetals，保留钢的 `scaffold` 旧 ID，新增 59 个材料变体。每种拥有材料颜色、对应 iconset 的杆件纹理、四种结构状态模型及生存配方。

`MultiTileEntityScaffold.java:78-110` 通过脚手架类型判断支撑，原版不同材料属于同一机器方块。本批将移植版按同一 Block 实例判定改成按 ScaffoldBlock 类型判定，恢复跨材料竖直/水平支撑与连接外观。移除支撑仍会掉落对应材质的脚手架。

`DungeonChunkRoomMiningBedrock.java:42,55-107` 的一次黄铜/钢抽样同时用于脚手架与栏杆。此前抽样只作用于栏杆，脚手架固定钢。本批把同一个随机值传入全部脚手架放置点，不增加随机调用。原版 Minecraft 工作台等按确认保留。

新增 `tools/generate_scaffold_family.py` 生成 60 条配方、59 套新变体资产和双语名称。中文全部取自GregTech.lang 对应 8400+aID。复用已核过的金属表和书架材料 iconset 记录，生成时验证纹理存在。

## 下一批已核实的缺口：炸药

读取 GT6 `MultiTileEntityDynamite.java:63-79,111-146,210-237` 后确认：NBT_MODE=mSunk 会改变嵌入模型及爆炸中心；remoteActivate 将倒计时设为 20；爆炸方块范围固定中心周围 3×3×3，NBT_QUALITY 是最大可破坏抗爆值，而非爆炸半径；跳过刷怪笼/基岩，实体伤害也另有规则。当前 `DynamiteBlock.java` 把质量映射为原版 TNT 爆炸强度，且立即起爆，无嵌入状态。这是实质行为差异，不能仅补贴图，下一批需连同地牢嵌入参数一起重做并替换旧测试中的错误预期。本批 Java 门禁期间仅核对原文，没有修改炸药代码。
