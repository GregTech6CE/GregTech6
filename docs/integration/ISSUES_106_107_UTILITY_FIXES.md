# Issue #106／#107：流体泉保护与手工浸洗交互

2026-10-25，分支 `codex/fix-utility-interactions`，基于 `9bdd17034`；与燃烧室 PR #130 分开。

- [#106](https://github.com/GregTech6CE/GregTech6/issues/106)：七种固定流体泉及旧元数据载体原本使用普通石块的硬度／爆抗。共同注册改为硬度 `-1`、原生基岩爆抗，阻止普通挖掘和爆炸破坏；创造取样、创造移除和原有出液代码保持。
- [#107](https://github.com/GregTech6CE/GregTech6/issues/107)：木板等配方原料同时具备覆盖板身份，覆盖板事件在原生槽位交互前消耗点击；潜行时还会被散装堆放置事件截走。两条路径现在都把有效原料交给手工设备处理，普通和潜行点击均可入料；保留前序显式拒绝及后续保护事件取消。
- 原版浸洗盆、搅拌碗和榨汁器都明确禁止覆盖板。对应七种现代手工设备停止接收新覆盖板；已保存的错误覆盖板仍保留、同步，并可用撬棍回收。普通机器的覆盖板准入保持。
