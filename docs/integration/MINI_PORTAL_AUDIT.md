## 已有功能与短探针

下界／末地两种实际门保留8／128距离因子及128／512误差范围，先按水平距离找最近目标、相同距离再比较高度差；边界相等时仍可选择。当前long乘法避免旧int中间乘法溢出，没有把这项保护列为缺口。查找跳过未加载目标，不能误报会自动加载另一维度的区块。

对面邻居地址及其朝向、共用物品／流体转发、GT能量转发和两端FE入口已有。持久化有激活字段，加载／卸载也有入口；这些源码存在不代表跨维度物流、保存重启或卸载时序实测通过。微型门不传送玩家／实体；地牢房间使用原版传送门是另一条消费者。

两种门的开启模型各13块、关闭框架各12块，所有盒坐标与原 sBlockBounds 对应。物品模型指向开启形态；这里只验几何／引用，不证明面剔除、纹理像素和游戏渲染一致。

约0.53秒仅编译／执行实际 core MiniPortalSignals、整理前仅更名的副本、原共用 onTickStart 信号主体及绑定表达式片段。保留原片段，明确省去父类委托并适配扫描目标／方法参数；不是另手写一套现实现作为原版oracle。16组时序／2048刻／12288面对照覆盖两种推进与接收顺序、0–15输入、多个发送者最大值合并和断流空窗，输出、最大比较值及变化标记一致。

该探针全部保持激活。下一刻投递、等待20次后再一次无输入才清零已核；没有执行原实体、Minecraft世界、停用／卸载或原生邻居通知。准备阶段的表达式提取、夹具编译与PNG元数据读取错误及修正已留痕，不能把它们写成生产功能错误，也不能省略后宣称首次全过。
