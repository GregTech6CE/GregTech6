# 消耗工具的声音、配置与生命周期核查

第四十三批，2026-10-20，基线 `8775232fc`。承接点火／灭火工具核查，沿真实物品入口追踪声音、创造模式预算和空耗材的最终形态。按要求先合并 `origin/main` 的四个 Addon 部件／管道提交，保留双方决策记录，恢复本批暂存改动；新增接口的定向验证另记，不声称已经审完新增 Addon 功能。

## ALIGN-132：点火、喷罐与胶带缺少物品层反馈声音

原版 `Behavior_FlintAndTinder:59` 在通过面阻挡门槛的服务端点击后发送点火声音，包括概率失败。`Behavior_Lighter:87,101` 在有效形态尝试前发送点火声音；`Behavior_Duct_Tape:70` 在成功封装后发送布料声；灭火喷罐 `Behavior_Spray_Extinguisher:74–75` 成功后发送喷射声与熄火声。

当前对应行为、`ItemBehaviors.useSpray`、两版多物品回调和起火器工具回调中均没有这些统一声音调用。雷管的 `onIgnite`／`onExtinguish` 自己发声，是目标层反馈；它不能覆盖概率失败或无目标的打火机，也不能替代原版额外的喷罐声。自动点火器另有自身声音入口，不列为失效。

结论限定为缺少明确的物品层调用，不声称附近世界绝不会因其他事件发声。本批没有客户端听音验收，也未替原版 IC 声音擅自指定现代音效。

## ALIGN-133：原版起火概率配置尚未接入

原版 `GT6_Main:111` 读取 `general.FlintAndSteelChance`，限定 1–100，默认 30；起火器行为使用该字段，原版 `GT_Proxy` 还在其他打火石处理里消费它。

当前 GT 工具调用方始终传入 `DEFAULT_FLINT_CHANCE=30`；`GregTechConfig` 没有对应设置。默认值一致，问题在于没有提供原版配置入口，不是普通材料默认概率错误，也不与 ALIGN-127 的二次判定缺失混为一项。配置收尾此前按要求延后，本批仅登记，不增加设置。

## ALIGN-134：胶带的创造预算与实际扣量错误

原版胶带将无限物品玩家的可用预算替换为该卷的完整 `mUses`，成功后不减少已存剩余量。当前 `BehaviorDuctTape.useOn` 总是传入 `can.remaining(prepared)`，成功后总是调用 `can.spent`。

此差异有实际宿主路径：大容量存储检查 `stored() > uses` 后拒绝胶带；原版同样检查存量是否超过预算。例如创造模式使用剩余 1 次的普通胶带封装含 100 个物品的存储，原版以 10000 次预算准入，当前以 1 次拒绝；剩余量足够时，当前又会真的扣量。普通胶带 10000、加强胶带 100000、BrainTech 10000000 及质量档位已经对应。

上述例子是源码数据流推导，不是游戏操作结果。当前喷罐和多次打火机已有独立创造豁免，不能扩大为全部耗材都会扣错。

## ALIGN-135：部分零余量耗材没有完成空形态转换

原版喷罐与胶带在处理末尾统一检查存储的剩余量是否非正，即使目标没有反应，也会换成空容器或减少物品。

| 初始状态与无效果点击 | 原版 | 当前 |
| --- | --- | --- |
| 非创造玩家，剩余 0 的已用喷罐 | 空喷罐 | 空喷罐，已对应 |
| 创造玩家，剩余 0 的已用喷罐 | 空喷罐 | 保留已用喷罐；空形态处理被包在非创造分支内 |
| 非创造或创造玩家，剩余 0 的已用胶带 | 胶带耗尽并减少一个 | 保留已用胶带；零返回的提前退出跳过清理 |

已用形态可以直接从创造物品列表取出，不需要先假定玩家篡改存档。剩余量为正的完整转已用，以及普通喷罐非创造耗尽处理已经存在；本项不推断流体、材料或任意标签复制漏洞。
