# 存储、料斗、机器读数与颜色拆分反馈修复

2026-10-20，基线 `2ecbb8eb7`。按玩家反馈优先修复；不是全面审计完成声明。原版作者 Gregorius Techneticies / GregTech-6 Team，沿用 LGPL-3.0-or-later 来源说明；源文件摘要与检查结果见同名 JSON 回执。

## 流体管网朝向与蒸汽脉冲

玩家配置为四个青铜蒸汽锅炉、小殷钢流体管道、青铜外壳／殷钢蒸汽涡轮，整套装置换方向后表现不同。源 `MultiTileEntityPipeFluid.onTick2/onServerTickPre` 把管道加入两个世界更新前队列，按 `WD.even` 的坐标奇偶交错执行。当前普通方块实体 ticker 直接分配流体，遗漏了这个时序合同，传输能受到邻居先后更新影响。

新增共享 `FluidPipeTickPhases`：原生 ticker 只登记正在更新的管道，下一轮世界更新前按原版两相顺序分配；相邻管道总属不同相位。队列每轮清空、过滤已移除／未加载实体，并在世界卸载时清除；不扫描或强加载世界。保留原版通道、回流标记、分配公式、容量和过载政策，没有增设吞吐上限。

定向场景使用真实注册锅炉、四段小殷钢母管、殷钢涡轮和青铜洗矿厂，旋转四方向，并故意反转东西轴的放置顺序。锅炉蒸汽罐被补至普通压力，以隔离燃烧和供水变量。旧直接 ticker 的首轮观察为四方向均值 30.8 RU/t，且四套均有过载声音日志；这轮没有复现玩家描述的轴差异，旧观察错误地读取了只给磁铁保存的过载键，日志中的零计数不作为证据。

恢复原版两相后，四方向最近一秒实收均为 **64 RU/t**，直接读取的过载保护计数均为 **0**。这是本场景下的改进证据，不代表任意供汽量或任意管路都不应过载。独立爆炸配置和原版应有的危险入口继续保留。

## 存储器与料斗

大容量存储补齐活动扳手位 1、剪线钳位 4、螺丝刀位 2 的切换，封装时仍可改模式；工具损耗按原返回值 10000 换算。实体实际执行向下输出、溢出容量 +256／仅输出超额部分，以及自动输出开启时的底面禁止输入。普通与物流材料子类共用实现。ALIGN-137 的这些执行缺口已修复；ALIGN-126 仅关闭该宿主的实例，其他工具入口保留待办；钳子／软锤 ALIGN-136 和覆盖板边界 ALIGN-138–139 不受本轮结论覆盖。

普通／队列料斗传输失败后会置休眠标记，而原版库存通知接口不由普通箱子或所有外部容器实现。增加每 20 tick 的后备重试，保留冷却、精确数量和红石门控；覆盖源箱子后来补货、目标容器后来腾出空间的恢复情况。基础机器的侧面物品能力额外禁止提取输入槽，GUI／内部处理仍使用内部库存。处理工具原有的输入／输出分离没有被取消。

2026-10-21 通知补核：上述后备重试继续有效；原 GT 金属／强化木箱本身另有六面专用通知，当前发送／接收链尚未完整恢复，登记 ALIGN-172。现代原生／外部容器不提供该接口与原 GT 箱缺少对等广播是不同边界，不能由此撤销已验收的重试，也不能再把专用通知视为已完整移植。见[第五十批报告](../INVENTORY_NOTIFICATION_AUDIT.md)。

## Jade 平均输入

以 20 个完整世界 tick 的实际入账能量求平均，排除尚未完成的当前 tick；多来源在同一 tick 相加，模拟和未入账超额包不计入。展示平均输入和 `平均输入 / 机器额定输入` 倍率。它表示额定输入比，不承诺不同配方、输出堵塞或并行状态下的最终成品速度。旧“工作中 0 RU/t”来自读取当下已耗尽的剩余缓冲，现改用实际输入均值。重载后的窗口自然重新积累。

## 十类颜色方块和兼容边界

沥青、混凝土、强化混凝土、干／湿泡沫、泡沫半砖、普通／荧光玻璃及两种玻璃半砖，共 **160 个颜色 ID**。例如 `gt6ce:concrete_red`；新方块没有 `COLOR` 属性，新物品不靠颜色 NBT／组件区分。

旧十个调色板 ID 保留加载已有方块状态；旧物品在原生存档解码时转为对应新 ID，保留数量、自定义名称等其他数据。旧方块拾取／掉落及放置路径也指向颜色实体。湿泡沫换色保留干燥计时；干燥、钢筋加固、地牢与 Nexus 放置保持颜色，半砖保留六向／九宫格实现。

旧数据包的调色板配方输入转为颜色家族标签，带指定颜色的面板配方使用精确新物品；输出指向新 ID。机器配方保留旧家族匹配及十六种查看器候选，并建立／移除对应索引。材料组成沿用原家族。创造栏、JEI／EMI 隐去旧兼容物品，REMI 分组包括全部新颜色；Neo 重复的旧染色注册入口移除，共享入口给所有变种染色。

320 个模型／状态资源和十个配方标签由 `generate_construction_colors.py` 生成；不新增重复贴图。160 个名称绑定原有原版身份，普通玻璃半砖误用荧光玻璃英文也按 `BlockGlassClear`／`BlockColored` 的原公式修正。中文逐字使用用户语言补丁；新增且没有原文绑定的界面文字按既有策略保留英文后备。
