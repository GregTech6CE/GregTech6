# 原版机器含材料数量与运输提示

日期：2026-10-07。基线：`60251872`。当前仅本地修改，未推送；整体移植 goal 保持 active。

## 采用的原版行为

材料采用原 `MultiTileEntityRegistry.add -> CR.DEF_REV_NCC`、`MultiItemTechnological` 的 REV 输入及显式 `OM.data`。`OP` 的原始重量、线缆橡胶副材料、`MT.DATA` 档位数组、`ANY` 输出目标及配方输出数量共同参与计算，单位始终为 `CS.U = 648648000`，不将显示用整数直接当成内部材料量。

共享目录有252条机器/档位记录、396个稳定方块身份，以及120种漏斗（普通/排队各60）。覆盖基础机器、五种加工多方块控制器，燃烧室、轴/两类变速箱/引擎、电动机/发电机/变压器/电池盒/太阳能板/蒸汽涡轮，以及命名多方块墙体、线圈、处理器、主阀和大型能源设备外壳。统计有交叠：五种控制器同时保留机器索引与稳定方块索引，不能将三项简单相加当作不同注册物品数。646条原版组成依赖参与计算。

两端从原生注册表接入同一个 `ItemComposition`；加工多方块不因使用独立注册入口而漏掉材料记录。删除原来统一8U壳体估算和引擎固定9U提示。含材料数量交由现有高级材料提示事件显示一次，同时保留熔点、沸点、质量等现有材料属性。恢复/坩埚消费者继续读同一个材料注册表，没有新建第二份数量模型。

独立固定来源核对包括：青铜离心机23U；LV电动机/发电机18U+U/3镀锌钢、1U磁化铁及1U铜；铱自定义变速箱14U、铱旋转变压器26U；内爆压缩机墙36U钨钢；大铱线圈16U铱；不锈钢小罐主阀4.5U；不锈钢大锅炉主压力计90U。蒸汽涡轮黄铜变种仍含原版青铜壳体23U与黄铜转子17U，不能把全部组成染成一种材料。

原版未知自动矿辞数据跳过，保留审计，不随意选标签首个成员。电路、砂岩、润滑剂、蜂蜜/水、镜片、早期起火器及兼容电池标签等没有在本次解析来源中找到自动材料数据。最大木轴24803的木梁/杂酚油没有自动数据，因此没有虚构8U。大型XV电池盒10099引用原版未注册的10049变压器；仅保留已知石墨烯，缺失引用单独列出。额外移植版变种和原版被注释停用的注册不冒充已恢复记录。解析器只支持已审核的常量/已知循环，不是完整Java解释器；未来来源改变需重新审核。

## 运输方块提示

恢复原版流体管每通道带宽 `capacity/2 L/t`，多通道数量及扳手连接说明，去掉流体管不支持的猴扳手连接提示。木桶也显示原版无GUI及导能流体销毁说明。桶物品读取现存原生存储格式中的实际流体、保存容量、密封标记和密封时间；未改变NBT/组件键、放置或保存格式。

20个运输提示原始语言键补入英文；对应中文已存在且与 `C:/Dev/GregTech_zh_cn.lang` 完全相同，没有自行翻译。原版源码中硬编码的流体/密封字符串仍保持原文字面值。抗爆等级、采集等级、接触伤害开关及其余方块专属提示仍在后续账本中，不能据此声称全部tooltip完成。

## 来源与核对

[来源账本](machine-tooltip-source-20261007.json)包含25个原版/中文来源的SHA-256、完整头部许可通知、GregTech-6 Team / Gregorius Techneticies署名、LGPL-3.0-or-later证据、所有逐条材料量与原配方、三份本地映射输入哈希、语言导入值及例外。

只读 `_w` 对照10种代表配方。文件整体不同；所选配方输入在 `Blocks.brick_block -> Blocks.BRICKS` 的原生API名称归一后全部相同，仅据此采用这些输入关系，没有宣称两个项目整体一致。

再生入口为 `tools/integration/generate_machine_material_data.py`，必须显式提供只读source及本地audit/out；语言导入入口 `tools/integration/import_source_tooltip_lang.py` 必须显式指定原版、中文补丁、使用原始键的Java文件和审计输出。旧配方/参数生成工具的机器档位解析器已适应去掉估算函数后的目录声明，79个机器定义保持可读取；未执行含旧硬编码路径的主生成入口。
