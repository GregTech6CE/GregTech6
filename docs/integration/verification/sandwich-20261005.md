# 2026-10-05 / 双版客制化三明治续批

在 NeoForge 1.21.1 发现的问题同时按 Forge 1.20.1 范围处理。本批对齐显式 MultiItemFood／MultiItemBottles 配料和基本三明治行为；整体移植仍未完成。来源与限制见 [原版记录](sandwich-source-20261005.json)，完整回执见 [实际记录](sandwich-20261005.json)。

## 实现范围

共享 core 保存95项显式配料注册、35项原版瓶装食品数值和105条可映射效果；瓶血在原版没有 FoodStatDrink，仍使用每层最低1食物／0原始饱和度。恢复原版默认样品的番茄酱层和调料颜色。原版16像素层槽、四片模型、涂层包裹与吐司轮廓由同一几何规则供两版世界与物品渲染器调用；物品模型按保存的真实配料显示，替换固定牛排三明治图片。

两端接入潜行右键吐司／烤吐司开始制作，每批最多16份；拒绝不足数量和连续相同顶层，瓶装调料按每4份1瓶向上取整，返还空瓶。数量保存在外层物品栈，物品内部每层数量规范为1；重新放置一份后只产生一份，世界中的批量数据仍按批量保存。复制选取保留实际配料，红石和比较器按层高输出。

食物值逐层求和，饱和度取各层最大值加0.5；营养统计和回调每层执行一次，避免按整批数量倍增或再次返还容器。蜂蜜／皇家果冻等的牛奶清除回调、恢复效果及手榴弹汁爆炸入口已接回。提示显示自上而下的层名称和原版红色食物行。

原版底层 `UT.Entities.applyPotion:3057` 对持续时间≤0提前返回，因此部分药丸的负持续时间移除声明实际上不会执行，本批保持此行为。Cure All 的牛奶清除与熄火仍执行。1.7.10四参数效果构造的最后参数对应 ambient，而非现代的隐藏粒子开关；现代效果保留可见粒子。
