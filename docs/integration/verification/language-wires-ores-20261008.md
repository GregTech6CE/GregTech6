# 导线、特殊矿石及设备名称与独立英文门禁（2026-10-08）

本轮仅处理语言及自检，不改注册 ID、电力参数、配方或物品行为。原汉化文件 125,676 项和原始字节不变。

## 来源与接线

- 620 个电力导线/电缆绑定原 `MultiTileEntityWireElectric.addElectricWires` 辅助函数的尺寸和偏移，按实际材料符号核对；电缆偏移并非连续序号，石墨烯/超导体也不生成电缆。两端 `WireBlockItem` 改用原生完整注册译名。超导体使用原 `tier` 声明提供英文名，不能因没有正数材料编号而遗漏。
- 6 个红石导线/电缆保留原 27000/27006、27050/27056、27500/27506；其中 Lumium 裸线是原 `Wirelamp` 名称。
- 12 个晶体、9 个层状矿石、16 个普通矿石按原 `BlockCrystalOres`、`BlockRockOres`、`BlockVanillaOresA` 构造器元数据绑定。原 `Sylvite`、`Oil Shale` 等名称不再由贴图路径拼出。
- 15 个激光转换器、4 个 ZPM 方块及 5 个锭/板/硬币堆和三明治方块接回原数字编号；旧 elite 放电器是同一个量子放电器别名。千吉卜计量传感器确认原 31023 英文，但原中文补丁无此键，保留原英文。
- 英文门禁与“原补丁是否有中文”分开：缺中文而有唯一原英文身份的条目也固定原英文，显式记录缺中文标记；门禁拒绝拿该标记覆盖已有译文、冲突别名、英文漂移或自行补译。

第一次导线解析提案因电缆条件块内有嵌套配方循环被拒绝，未写入语言。修正为平衡括号读取条件范围；针对尺寸缺失、错误条件和无电缆材料的快速检查均通过。

## 结果与验证

新增 687 个中文来源绑定，英文和中文各新增 620 / 修正 67 个值；14,218 英文键、141,356 中文键、12,546 别名、7,849 固定原英文声明，其中 1 条明确缺原中文。3,135 英文后备键包含旧键、模板和原缺译，不能当作游戏缺译物品数。

46 个快速检查 1.146 秒、2,601 Java 源码门禁 2.888 秒、外部原汉化文件逐字校验和再次导入零变更通过。双平台主代码与独立自检入口合并编译 56 秒退出 0（11 项任务，5 执行、6 复用）；新增中英各 688 个实际名称检查已编译，尚未启动运行。来源文件、当前文件哈希及差异见[证据](language-wires-ores-source-20261008.json)。

遵循用户减少重复测试的要求，本批没有重新构建普通 JAR、验包或启动游戏。最后接受的双包仍为 `build/verified/20261007-233043Z-a5f440e8/`，不含本批修改；实际客户端检查与后续语言批次合并进行。

全汉化仍未完成。旧实际名称清单中扣除已绑定内容后，非材料、非流体、非石材的未绑定候选尚有 112 项，包含移植新增内容、原缺译及待查身份，不全部视作可直接翻译。流体、材料形态、现代 UI 缺译也仍需处理。继续语言范围，达到用户条件后暂停；仅本地，无推送。
