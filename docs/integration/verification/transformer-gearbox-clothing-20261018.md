# 普通变速箱物品模型与服装分类

新截图的钛变速箱为 512 RU/t 输入、128 RU/t 输出，对应 `rotation_transformer_titanium`；`gearbox_titanium` 是可调变速箱，1024 RU/t。此前数轮仅检查后者 13 种材料，定位对象错误。

普通变速箱双平台共 26 份物品 JSON 使用 `{"model": "…"}`。`model` 是方块状态中的引用字段，物品模型必须通过 `parent` 继承。旧 JSON 不包含 parent 或 elements，因此能被读取却没有可绘制面；方块状态另行指向正确模型，所以放置后有贴图。已全部改为 `parent`，复用已有普通变速箱双层方块模型；材料颜色、齿比和世界渲染不变。生成器也改为直接生成正确继承字段，避免错误模板再传播。

移除此前仅针对可调变速箱 REMI 分类的普通绘制回退 mixin。此回退未解决错误的普通变速箱空模型，也不应保留为根因修复。已有 REMI 探针改为分别核对两个家族，各 13 个材料，并检查普通变速箱实际贴图面。

全部六套防护服共 24 件，依据共享 `HazmatSuitCatalog` 枚举加入同一个 `functional_clothing` 组，通用标题“服装 / Clothing”。分组数 450 → 451。实际名称和原版汉化不变。

轻量核验：一个定向回归检查解析双版两个家族的 52 个物品根模型及其父链，确认存在至少六个贴图面，0.041 秒通过；451 组生成一致性及差异检查通过。没有运行客户端或完整测试，也没有构建新的交付包。新增运行探针尚未执行，GUI 视觉待下次启动确认。

后续目标：先在 main 提交上述修复，再在 `experiment/stonecutter-emi` 分支接通此前预留的 11 个 EMI 类的 Stonecutter 预处理与原生编译，验证双版构建入口并记录剩余迁移边界。保留 core 和平台资源结构。旧长期目标当前仍为暂停状态，因此本文件记录本次具体目标；不将旧移植目标虚报完成。
