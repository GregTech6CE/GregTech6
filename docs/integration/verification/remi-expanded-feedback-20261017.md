# Reliable EMI：建筑、功能物品、真实流体与分组标题

本批基于 `1a2a7e3ac`，仍在 main；不推进 Stonecutter 或其它移植大项。

## 实现范围

- 板材组显式排除原版玻璃板、纸和对应 GT 纸板物品；原版透明／染色玻璃板单独一组，纸单独处理。只有一个可见成员时 REMI 显示单件是正常行为。
- 共享资源从 346 增为 390 组。补齐沥青、湿／硬建筑泡沫、泡沫半砖、混凝土／强化混凝土、GT 玻璃／荧光玻璃和荧光玻璃半砖。颜色是物品数据变体，不是不同注册名，因此按同一个物品身份匹配所有颜色。兼容旧湿／硬泡沫身份。
- 当前两平台没有注册普通 GT 玻璃半砖；本批仅归类实际存在的半砖，没有凭空增加方块。
- 集成电路、宝藏箱、光莲、普通／低热容压模模具、机器传感器／传感器部件、液体泉、书架、栏杆、瓶筐、木梁、自动点火器、自动锻造锤、充能工作台、CO2 激光器、激光接收器、黏土模具、帆布、一次性工具、饮料、食物、冰淇淋、普通／大号书分别分组。蜂巢沿用前批完整分组。食品／瓶装饮料成员来自实际 MultiItem 分类；冰淇淋独立于其它食物。
- 液体燃烧室／致密液体燃烧室各 14 个材质身份分开；新增远距离输电线、远距离变压器端点、电磁铁、大型电池盒和普通变压器。大型电池盒真实前缀为 `energy_storage_`，电磁铁为 `electromagnet_`。
- 真流体支持：REMI 两平台的 `EmiStackGroup` 使用类型前缀候选串，`^fluid:gregtech:...$` 只匹配 GT 的真实流体，不会吞并同名物品、FluidItem 或其它模组流体。查看官方源码的本地缓存 `work/pr-review-20261016/remi/{1.20.1,1.21.1}-EmiStackGroup.java`；来源 Evan Bowness / Reliable-EMI，MIT，既有来源记录适用。没有复制第三方实现或打包依赖。
- 两平台液体泉物品名动态组合既有“液体泉”原译文与原生流体名称，显示“液体泉（对应流体）”。不修改注册 ID、流体输出、旧存档或原语言别名。

## 追加的机器主标题

140 个机器／功能块分组标题采用原有名称的确定性投影：去掉材质和电压等级，保留燃料种类、致密／强化、轴规格等功能限定。例如 `自动点火器 (LV)` → `自动点火器`，`燃烧室 (液体, 砷青铜)` → `燃烧室 (液体)`。展开后的物品名称不变。

此项依据本轮明确要求，取代上批“完整代表物品名称”的选择。新标题有独立 `emi.group.gregtech.functional_*` 键，由 `remi_group_titles.py` 从已有源绑定文本派生。汉化自检重算投影，英文也必须与源名称投影一致；原物品／方块翻译仍逐字对照原补丁，既有 12836 项英文声明和原译文规则没有放宽。统计单独列出派生标题，不伪称原补丁新增了这些键。
