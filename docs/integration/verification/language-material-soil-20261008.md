# 材料身份、英文显示名与地表方块译名

本批承接 `9c0f0dd4c`，仅修改共享语言资源、来源导入器和快速检查。用户要求全部汉化及中英文自检完成后暂停；当前尚有原补丁缺译及来源核对工作，不宣告完成。

修正 17 个历史材料别名绑定。当前共享材料导出正数 ID，与原 `MT` 构造器的 ID、经 `OreDictMaterial.sanitize` 处理的内部名共同核对。原 ID 8513 的 `Moon Stone` 是月球岩石，8452 的 `Moonstone` 才是宝石；当前材料使用前者。旧字段 `CrudeSteel` 对应 ID 8806 的 `Clay Compound`，因此中文照原补丁使用“导管粘合胚料”。ID 0 占位声明不作身份证据，重复 ID、大小写不符和多义字段不强行匹配。

英文导入补充材料的字面量工厂、链式赋值、`woodnormal` 显示名以及 `setLocal`。原 `MT` 初始化调用 `ANY.init()` 后，材料组显示名已从 `Any Iron-Steel` 等变为 `Steel` 等；修正此前遗漏初始化覆盖导致的 76 个机器名称及 51 个材料组名称。铜、铁、氢等八个旧符号的英文曾误写成反物质名称，也按已绑定的原材料声明纠正。新增固定英文声明 1334 个，旧声明无丢失；未知表达式不伪造英文。

四个名称碰撞已按实际材料的语言键及原编号解决：`cinnamon`、`gold`、`lime`、`magic`。同名木材字段不能覆盖实际材料名称。`ash`、`co`、`hf`、`no` 仍是多义兼容字段，保留审计，不按遍历顺序选择其中之一。

地表方块补齐原元数据身份：七类 `BlockDiggable` 与两个旧兼容 ID、六类 `BlockGrass`。草颜色按原 `GRASSES_TOP` 顺序 medium/light/dark/normal/yellow/brown，五种粘土及淤泥从物品球名称来源改为方块来源，淤泥不再显示“泥球”。这不把使用草捆贴图的旧 grass/dry/moldy/rotten 图标块冒认为原六种草方块。

`grccore.saltwater`、`tropicswater` 和 `stagnantwater` 的原 `FL` 身份在 `MultiItemBottles` 中明确共用内容名称，分别照原瓶装条目 1/1/7 使用原“盐水”/“死水”译文；这些原英文名称没有容器名词。其它含 Bottle 的条目没有用于给流体改名，也未猜译外部模组酒类。

本批合计新增 12 个绑定、修正 24 个绑定；273 条英文、20 条中文实际内容改变，无语言键增删。现 13506 英文键、140645 中文键、11704 别名、6427 个原英文固定声明。原中文 125676 键及 SHA-256 `0e5b3906712020b71c9c5718319bbf3fd90b002d79d25614f1bfcaf3c8e887c0` 不变，中文全部来自该文件。

37 项相关快速检查在 0.650 秒通过，包括材料编号/大小写/占位/碰撞、木材和 ANY 名称覆盖、语言格式及回执边界。开发身份导出由 Java 17 实际编译执行；初次缺少 Map 导入的失败已修正，不计作通过。源码门禁核对 2599 个生产 Java、771 个静态语言调用、11704 绑定，2.811 秒通过；501 个动态边界仍需目录/成品检查。重复导入新增/冲突/英文变化均为零，外部中文原文件逐字节核对通过。
