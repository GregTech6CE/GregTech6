## 原生世界与配方证据

最终命令包含 `:build :neoforge:build :runGameTestServer :neoforge:runGameTestServer -PgameTestNamespaces=gregtech_alignment -PgameTestHeap=3g --offline -I work/emi-local.init.gradle`，成品构建没有使用直接 core 资源/类路径的开发快捷参数。

共享 8,139 条断言、Forge/NeoForge 各 8 项原生 GameTest 通过。两版分别实际合成全部 81 条可用手工/工具头矩阵，并合成 JEI 目录的 9,053 条材料样例，检查产物和催化工具磨损。工具样例来自真正 RecipeManager，不以目录自身存在作为制作成功证据。最终正式构建与双版世界回归合计 4m18s，日志及哈希见回执。

实际注册青铜锅炉 → 无转子青铜涡轮 → LV 发电机 → 镀锌钢电解机，在 2,758 个手动 tick 后将 6 份高氯酸锂粉送入真实接收箱；最高输入 22 EU/t，配方 16 EU/t、256 tick。热量 80 HU/t 与蒸馏水由测试外供；蒸汽全部由锅炉生成。没有直接给涡轮、发电机或电解机注入能量。该夹具证明指定机器和配方的完整处理，不代表从采矿开始的整条生存链。

两版可见矿处/回收配方数量一致：Crusher 6,623、Bath 1,154、Centrifuge 834、Shredder 42,744。真实原矿输入的保证产出通过；三种焦炭十二种形态的燃料和灰量通过，生存玩家正面插入焦炭、点燃和实际燃烧通过。锅炉冷空安全、20% 压力生存拆除爆炸、创造豁免通过。
