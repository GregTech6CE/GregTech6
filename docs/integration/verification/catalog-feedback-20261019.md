# 分类、旧测试磁铁及砧上方块显示

本批为 2026-10-19 反馈的分类与提示子项。双版共用规则；不改变瓶子的原创造分类、饮用行为或配方标签。静态数据与来源摘要见 [回执](catalog-feedback-20261019.json)。原始参考为 Gregorius Techneticies / GregTech 6 Team 的 GT6，Java 按原 LGPL-3.0-or-later，原有声明保留。

## 实现

- EMI 不能以 `MultiItemFood` 的类别名称判断可食用性：该表也注册蜂巢、牛蹄、草、树皮、黏土等。现按已采用的 `GTFoodItemsGen` 食物统计区分，20 种蜂巢独立归组；食品细分水果坚果、蔬菜、肉鱼、蛋乳、面团、烘焙、三明治、披萨、土豆制品和冰激凌。动物部件和自然原料／副产物单列，保留已有黏土类别。
- 瓶表的汞、墨水、靛蓝染料、毒药、焦油、血、润滑剂及胶水属于工业试剂瓶。烹饪油和调味料、药物另外归组；这些仅是 EMI 分类改动。
- 发霉草垛被错误分入模具，是旧导入器去掉所有标点后，把 `Mold` 当成 `Moldy` 的前缀。匹配现在要求完整词边界；八种草／作物草垛使用自然与食物创造页。
- 三个 `_2` 胶带是原版已开封物品，分别绑定原 `12001`、`12003`、`12009`，不再按同名误用未开封的 `12000`、`12002`、`12008`。原文 `Used Roll` 与补丁的“已开封”逐字采用；原始汉化补丁不改。
- 删除早期十个无配方、无磁场功能的 `magnet_*` 测试装饰块，删除注册、旧染色分支、27 份模型资源及两个 EMI 组，不留兼容别名。三份电磁装饰块模型在本批前就不存在。真正的五档电磁铁及五档磁通磁铁、配方与磁场能源逻辑保留。原版依据为 `Loader_MultiTileEntities.java:865–876`。
- 砧上外部方块之前统一走 `.28` 的 `FIXED` 物品模型；现为 `MODEL` 类型的普通 `BlockItem` 直接调用方块渲染器，并放入原版 `shape 7` 的工件范围。GT 材料形状和非方块物品回退保持。静态检查放入、取出、更新标签和更新包均携带两个 `gt.work` 槽，没有发现这一项的同步遗漏；原版依据为 `MultiTileEntityAnvil.java:151–215,306–318,357–381`。

## 验证边界

已做生成资源逐项比对、所有食物组交叉排重、蜂巢与试剂瓶边界、旧磁铁源码／资源无引用和 Python 语法检查。一个胶带编号解析回归用例通过；第一次沙箱临时目录权限失败后，同一用例以正常文件权限运行通过。客户端 REMI 探针和旧磁铁探针更新了预期，本子项没有运行它们。

原生双版编译由主任务统一执行。本子项没有运行 Gradle、GameTest、游戏客户端或打包；砧上矿块的最终视觉、EMI 实际展开收起、创造页以及旧存档重启仍须实机核验。删除旧测试身份的存档兼容不作承诺。

本轮共 464 份 EMI 分组资源。严格双语同步通过：英文 15,918 键、原版固定英文声明 12,883 条、中文 141,745 键；原始补丁 SHA-256 不变。全量身份提取器的旧 hazmat 声明保留守卫拒绝重建时，没有放松守卫；改为仅修改这次证明的六个胶带绑定，保留其余 12,877 条已核英文声明。完整提案失败日志和最小修复回执保存在 `work/feedback-20261019/`，来源摘要与最终结果进入本批 JSON。
