范围为 Forge 1.20.1 和 NeoForge 1.21.1。此前仅在 1.21.1 发现的问题不能据此排除 Forge；本批每项实际配方和模型检查均执行两版。整体移植仍未完成。

## 改动

- 恢复原版 20501–20505 的五档闪电处理器，移除共享定义及两版制作包中的错误多方块排除项。复制已有原版机器模型、补齐两种语言，保持原版 EU 档位、4 点硬度与配方。电极使用铁／钢材料族和对应 1/2/4/8/16 股导线，拒绝任意导线替代；工作导线为对应电压的四股线。自动流体输入、输出改为上、下方。
- 熔化器恢复原版铁机壳、HU32、并行1000和廉价超频，保留已交付 `melter_stainless_steel` ID。制作允许原版铁／钢机壳与中型管道，避免不存在铁流体管时被悄悄替换为机壳。
- 机器原料解析加入原版物品管道。OP.pipeMedium/pipeLarge/pipeHuge 同时用于原版物品管和流体管，不能只查流体管。精确流体管优先，缺少时查询同材料、同尺寸的普通物品管。
- 恢复现有长距离 ID 的 15 条原版图案配方：六条导线（含旧兼容导线）、两条管道、两个端点、五档长距离变压器。塑料板与铜曲板接受原版材料族，物品管用琥珀金普通物品管、物品端点用铂普通物品管，流体端点用钨流体管。
- 修正发电机、大型电池盒和长距离设备的创造栏分类。移除按任意 ID 包含 `zpm` 就归入 ZPM 页的规则，防止高阶变压器、电池盒及长距离设备被错误移动。
- 共用并行耗能按原版 BasicMachine:730/743/766–773 区分：增加功率的并行批次，最低功率乘以并行数；增加耗时的批次，总工作量乘以并行数；TU 保留时间模式。两版非时间并行批次按额定输入限制，避免消耗过低或超过输入功率后卡住。
- 机器配方/参数生成器改为读取共享 `BasicMachineCatalog`，输出共享 core 表；拒绝没有读取到定义时生成空表。共享资源接入项目已使用的增量资源任务，后续构建只同步变化。
