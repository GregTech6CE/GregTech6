还确认：

- 两个实际包都没有同名重复条目，也没有嵌套依赖JAR。共享core和平台类并不是重复嵌套两份成品。
- 每包18,402个PNG中14,315个与其它路径内容相同，多份压缩内容约4.54MiB；这属于共享贴图优化候选，**不能据此认定这4.54MiB都是与对照版的差距**。对照源码贴图的压缩内容估算反而略大于当前包。JSON也有字节相同的重复内容，但路径可能是有效游戏资源，不能直接删除。

- 中文文件原始8.45MB，压缩后1.318MB，汉化不是主体原因，不应靠删翻译缩包。
- Forge/Neo各10/5个原素材BAT工具混入资源，压缩内容仅数KB，属于小规模交付清理。
