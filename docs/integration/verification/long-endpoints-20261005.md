# 2026-10-05 原版长距离端点交互、颜色与接收端认领

承接长距离材料管线续批及双平台渲染/工具反馈。本批补齐两种管线端点与五档变压器端点，不宣布完整物流、完整机器面板或整体移植完成。彩色书籍已在此前提交及本次继承的成品中，阅读证据见[书籍记录](coke-books-20261005.md)。整体移植仍未完成，未推送。

## 实现与来源

原版三种端点均默认朝上，允许六个方向；按原版 `UT.Code.getSideForPlayerPlacing` 的正负65度阈值放置。两端接已有扳手3×3选面和客户端旋转提示声明，使用扳手旋转、软锤重新扫描、放大镜显示发送/接收角色与坐标。软锤不切换开关状态；开关接原生 `MachineControl`，停止标志随原生数据保存。原版工具点击返回10000/10000/1，换算为现有手动工具耐久100/100/1；电动工具沿用已有耗电机制，不重复扣除。

物品端点铂、流体端点钨；五档变压器分别铬、钛、铱、锇、Trinitanium。端点堆叠上限16，采掘接对应材料工具等级。两端复用原图的可染色底层和固定色覆盖层，新增六向方块状态、变压器四种活动状态及平台原生composite模型。NeoForge颜色包含不透明alpha；Forge通用杂项颜色回调排除这些独立端点，以免覆盖材料RGB。

原始Java快照有变压器活动图标路径声明但缺对应PNG，采用提供的 `_w` 保留快照中9张原图及3份动画元数据，字节不改。代码LGPL-3.0-or-later、图片CC0及全部来源哈希见[来源清单](long-endpoints-source-20261005.json)，保留原作者和头部。

路由规则移入共享core：同元数据身份的广度优先扫描选择第一个正面接入的接收端，允许分支，不再要求整个网络只有两个端点。接收端认领一个活发送端；其他发送端不能抢占或跳过该接收端，原发送端移除/重置后可以重新认领。已作为接收端的端点不会因软锤而改为发送端。物品/流体能力对六个查询侧开放，面朝向定义管线连接和输出容器方向。

初扫读取路径区块，不再加4096节点上限；建立连接后保存目标坐标，不持续加载路径区块。长距离拓扑变化的世界版本触发缓存检查，避免每个电包扫描整个监视集合；只忽略未加载路径，不忽略已加载路径中的断线和转向。变压器显示状态变化不会造成路由重扫。未加载目标拒绝转发。真实未加载路径/接收端卸载的运行验收仍未完成。

电包保留符号，每包损耗 `max(64, distance/8)` EU；接收端从背面向真实能源设备输出。入口按原版根类先判断接收端存在，再执行过压处理，避免未连线的变压器被拒收电包炸掉。连续64 tick活动为1，闲置0，间歇2；停止时为0并保留历史。状态3按“已记住但当前不可用的目标”实现，未照抄原版同时检查接收认领的复杂条件，作为明确移植取舍。

## 验证范围

只运行共享检查和受影响的有限新世界，不运行整套GameTests、书籍、食品或浏览器回归。两端世界各检查29真实制作行、21掉落/模型/提示，六向30物品/168流体/24能源模拟检查；七端点42扳手旋转、28放置角度、7软锤、7放大镜、7原生停止数据往返，132真实朝向/活动模型前面底层与覆盖层及7种世界/物品颜色。

每端六向实际EV电池盒接收正负共18个电包：总输入36864 EU，收到35712 EU，损耗1152 EU；模拟没有增加电量。分支选择与活发送端认领/移除后释放6项，已加载的40格跨区块物品插入17/提取7/剩余10，共9项。这些是已提供设备的有限玩法证据，不能代替生存获得、专服或完整物流网络。

Neo首次世界通过后，来源复核补正停止/不可用期间保留活动历史；两条来源固定样例进入共享检查。Forge世界检查了这一版历史规则。随后修正根类接收判断与过压的先后顺序，并增加五档未连线过压拒绝夹具；最终Neo世界单独检查该边界。Forge未为这个两端相同的入口顺序调整重复整轮世界；其对应原生边界仍未单独运行，最终编译、成品字节验包和正式Loader主菜单分别记录。之前已通过的Neo世界保留为中间证据，不以它声称最终边界已验收。

原生数据往返使用真实 `BlockEntity` 保存/加载方法；没有独立保存后重启、旧世界转换、实际未加载区块、完整电压/过压烧线组合、IC2等第三方能源、生存取得或完整覆盖板/面板验收。工具夹具核对现有旋转提示声明与实际模型；未提供玩家持工具时提示网格的专门截图。
