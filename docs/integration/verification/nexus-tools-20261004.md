# 2026-10-04 / Nexus 测试工具箱查漏补缺

本批按原版 WorldgenTesting 的 144 格表达式逐格处理，补齐此前 22 个本模组缺项。整体移植仍未完成；这不是 Nexus 全部细节或整个模组的完成声明。

## 内容与实际功能

- 三种枪械（手枪、卡宾枪、步枪），保留测试箱内钢/云杉、下界化钻石/浅蓝、魔法钢/品红九个来源栈。弹匣分别 16/8/4 发，匹配小/中/大子弹；潜行右键装填或卸弹，右键由服务端判定命中、有限弹药、枪械磨损及黄铜碎屑。按来源材料密度/工具品质及射击能量算伤害；读取枪械和子弹的原生附魔，弹药使用 Damage+Ammo 分类及口径抢夺倍率。接入薄障碍穿透/玻璃碎屑、液体减速、装甲穿透、着火、击退及末影生物限制；组合边界未全部实际验收。
- 折叠多功能工具：关闭及刀/锯/锉刀/螺丝刀/剪线钳/剪刀/凿子八种原生身份。潜行右键切换并保留材质/磨损/耐久；保留来源四倍耐久及各模式参数，提示的伤害、速度与剩余合成次数读取真实折叠模式。模式接入合成工具身份与机器工具接口；补剪羊毛、锉金属栏杆、锯下完整冰块/树叶及螺丝刀交互，Neo 凿子原生匹配接受折叠模式。闭合状态按来源九格图样制造，产物柄材质 Blue；未补原版 8 条单格合成换档捷径。
- 电动工具总计 14 项：新增采矿钻/搅拌器/圆锯/修枝器 LV，以及扳手/采矿钻/链锯 MV、HV 六档，保留四个既有 LV ID。各档使用本档电池/电机或活塞、机壳材料、来源合成图样与工具头材质；源容量 LV/MV/HV=32000/128000/512000 EU，充电沿用有限电池接口。采矿钻支持石土采掘、物品栏石土堵漏和火把放置；搅拌器使用真实搅拌碗配方并耗 EU；圆锯针对金属栅栏；修枝器剪取树苗/藤蔓。对齐采掘、合成、攻击耗电与随机磨损。
- 将已有 Signalum 绝缘红石线及 Lumium 发光裸红石线正确解析入测试箱，保留其信号传输功能。
- 新增对应模型与中英名称/用法/口径/弹匣/电量/档位提示；动态材质头、柄与装饰分别着色。修复原版表达式材料名后对齐空格的解析遗漏，以及导入器漏识别 Pistol/Rifle 构造函数前空格造成的世界生成报错。共享检查覆盖全部 48 类原生手工具及 14 类电动工具的来源分类。
- 承接前续显示问题：物品渲染使用实体材质 sheet，旧齿轮箱把该层过滤后出现透明；现在物品先返回壳体六面，Forge 使用原生库存变换。六根绳子模型主体加入 tint，Neo 注册原生颜色并保持 alpha=255。四类过滤器已有正确来源镀锌钢 RGB `faf0f0`，保留近白色并在实际渲染查询中核对。
