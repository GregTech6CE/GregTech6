# 覆盖板厚度与太阳能板含水修复（2026-10-11）

## 实现与来源

按原版 `ICover.BOXES_COVERS/BOXES_HOLDERS` 和 `TileEntityBase06Covers.isCoverSurface/usesRenderPass` 区分完整面与附件：完整机器表面保持贴合，非完整宿主（管道、线缆等）增加方块边界内两像素厚的盖板、背面、侧面及中央支撑杆。碰撞与渲染使用共享 `CoverPlateGeometry`，不会向机器外抬高一像素。宿主判定读取无工具选择扩大的轮廓，避开已经包含盖板的碰撞形状。

泵、输送机、机械臂的内外纹理按原版反向；材料板和面板保留染色。火把、中继器使用原细柱边界和对应亮灭贴图，不套用普通大盖板。补入八张原资源及图集入口。来源哈希、作者和 LGPL-3.0-or-later 归属见 [来源清单](cover-depth-source-20261011.json)。

两版太阳能板状态仅保留朝向和发电状态，移除 `waterlogged`，放置、流体状态、水桶填充/抽取均安全拒绝含水；其它能源设备的含水能力保留。旧资源的四份太阳能板方块状态文件本来没有含水变体；生成脚本也排除太阳能板，防止重新加回。
