## 基岩钻机核对结论

基岩钻头是结构部件。原版钻机底部需要 3×3 基岩／基岩矿层，上方 3×3 钻头，再上方四层致密钛壁板，主控位于顶部中央。主体既有实现与这套布局一致。

一次产出使用 32768 RU 和 100 mB 润滑油，保留基岩本身；输出按基岩矿种与原版权重选择，并非直接挖除基岩。主控原版允许各面 RU 接入和物品抽取，移植版此前分别限为内部端口与上面，本次解除这两项多余限制。结构侧面四个旋转动力端口仍按布局约束，自动推送仍朝上。

未据此宣称所有原版兼容分支完全等价：HBM 等外部模组的特殊矿床／维度分支、缓冲容量边界及真实运行循环未作本轮实机验收。
