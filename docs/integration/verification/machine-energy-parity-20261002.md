## 实现与选择

Forge 与 NeoForge 基础机器共同调用 BasicMachineEnergy 的整包需求、接收、限容量累加和每 tick 放电；共享 MachineWorkCost 负责不溢出的作业进度。停机时仍能显示理论连接，但不再接受实际或模拟输入；真实输入标记存档脏状态。拉取邻居能量之前先限制为实际需求，避免把邻居全部能量取走后丢弃超容量部分。

保留 saltnya 的完整机器规格、注册、配方/覆盖物和 NBT 字段。吸收 masson 的有限缓冲与溢出安全原则，但不直接复制其不同的整包取整及第二套机器底层。参考 brokestar 的整包记账/单位分离；不额外添加 EU/FE 比率或第三套能源网络。按原 GT6 doInject/isEnergyAcceptingFrom 的停机与理论查询语义修正。保留当前向上取整接收并截断最后一包余量、每 tick 按最大额定功率丢弃未用输入的行为，不降低配方功率。

旧存档能量超过容量不再返回负接收量；极大包数的乘积和接近 Long.MAX_VALUE 的作业进度不再绕回负数。既有 NBT 名称/单位、配方与概率输出不变，不声称支持任意来源旧档迁移。
