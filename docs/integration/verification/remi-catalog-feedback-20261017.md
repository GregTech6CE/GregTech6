## 分类与标题

共享 Reliable EMI 资源从 390 增至 435 组，供 Forge 1.20.1 和 NeoForge 1.21.1 使用。整机分类要求后缀匹配实际材料身份，破碎机滚轮、研磨机刀片以及其它结构部件不再被机器名称前缀吞入整机组。

新增远距离流体管道、量子充能器、切片刀片与食品模具、微型电机、电动活塞、力场／信号发生器、喷漆、树叶、树苗、基岩矿指示花、普通／致密壁板、线圈、普通／致密多方块储罐、大型坩埚、蒸汽／燃气涡轮机核心、木板、电路板／成品电路／元件／主板／蚀刻线路／晶体电路、魔法研究论文、开孔原木、油田指示草、计压瓶、粘土块／粘土球、量杯、绳子、炸药、机械臂、指南针、钥匙、草垛、USB 存储器／硬盘／数据线、中继器、扩展桥和研钵。原生 `circuit_board_*` 对应焊接前的电路板；按原身份独立归类，没有另造“未焊接”物品。远距离物品管道只有一个可见身份时保持单件。

粘土模具组包含未烧制的龙头、坩埚、浇铸道、盆、杯等器具，标题改为“未烧制的粘土模具与器具”。已烧制陶瓷模具保持原分类。原 MultiItemFood 中的五种粘土球和未烧制粘土蜂巢从宽泛食物组排除，否则其 120 优先级会覆盖粘土组。

所有分组采用形态／用途标题，移除代表物品的材质、电压、颜色、蜂种和口味，保留导线尺寸、普通／致密、普通／强化、燃料种类等分界。使用 300 个独立 `emi.group.gregtech.*` 标题；其余材料形态沿用已有通用分类键。不可由一个代表物品表达的组合组使用明确要求的界面词汇，记录在 `remi_title_labels.py`，不冒充原版物品汉化。

既有非分组语言项逐项保持原值：英文 15521 项、中文 141372 项。原补丁原文及 12836 项原英文声明的自检规则保留。

## 重复身份与兼容

`LegacyContentAliases` 记录 19 个确认的兼容别名：

- 十种 `key_<material>` 统一到原 MultiItem 的 `<material>_key`。原 MultiItem 键已接入 `GTDungeonKeyItem` 的开锁／锁号行为；地牢新钥匙使用统一身份。旧键仍有原行为和数据，不删除存档内的键。
- `large_crucible_wall` → `coke_oven_wall`，原 18000 耐火砖；`boiler_wall` → `tank_wall`，原 18002 不锈钢壁板。
- 蒸汽／燃气涡轮旧壁板 → `tank_wall_dense`；旧发电机／聚变线圈 → 对应大型铜／铱线圈；旧热交换壁板／低温蒸馏壁板 → 热传递装置／蒸馏塔部件。
- `zpm_discharger_elite` → `zpm_discharger_basic`。原版只注册 11170 量子、11171 电力；电力版保留独立身份。

旧注册保留为存档兼容入口，从创造栏、JEI、EMI 索引隐藏。结构检查接受确认同源的新旧壁板，挖掉旧结构部件返回统一部件；放能器掉落转换保留其方块实体数据。机器配方原来引用旧壁板时，标准部件排在第一位，旧部件也仍可作原料。

`fire_bricks`、`stainless_steel_wall` 等另外的同名字符串仅出现在原版创意目录／语言数据，不据此误删注册。还有刻意保留的一组旧涡轮／发电机控制器转换入口，已核对两套路径共用等级定义且原有转换配方明确标注 legacy；本批未删除这些控制器或假称完成全库注册去重。名称相同不能证明储罐、旧坩埚和旧锅炉参数等价。

## 枢纽与草垛

双版 `NativeOriginWorld` 将 `source:sands` 的三个 metadata 映射到共享 `BlackSandDefinitions.IDS`：磁铁矿砂、玄武岩矿砂、花岗岩矿砂；复用河流矿砂生成所用的真实落沙方块，替换错误的 `block_dust_*`。新生成区域生效，不扫描或强改既有世界的粉末块。

草垛两版都注册为 `BaleBlock`，放置后 2400–4799 tick 安排首次检查，后续 1100–1299 tick 重试，仍有原版随机、温度、日照门槛。干燥时鲜草垛变干草垛，湿润时发霉，霉草继续腐烂；保持柱体朝向，下界鲜草可干燥。核查补上原版 `BIOMES_INFINITE_WATER` 条件：海洋、河流、海滩标签和原版已知水域名称也算潮湿，不能只看降雨量或邻水。
