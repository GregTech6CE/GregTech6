# 2026-10-18 空标签、模具链与变速箱物品模型

## 修改范围

- NeoForge 共享物品标签清单由 39 补齐到 69 项，覆盖扁平化蜂巢、泥、黏土球、水银等新增标签。新增清单生成器，并将清单一致性接入轻量源检查。
- 两版补原版木箱、染料、黏液球、砂岩、唱片与红砖标签；锇／艾德曼／基岩合金采用现有材料的别名，不新增虚假材料。导线、电缆按材料与规格生成 `wire_gtXX`／`cable_gtXX` 标签。
- 删除按物品含料量 2U 推断矿石、9U 推断材料块的逻辑。轴、木头和其他部件不再因此进入矿石转换；原版矿石和材料块由明确身份识别，GT 方块由自身类型识别。
- NeoForge 工具标签按注册工具类型生成，不要求空样本提前具备材料／耐久数据，修复刀、擀面杖等标签缺失。
- 从原版恢复 16 条曲柄／激光接收器／自动锻造锤／自动点火器配方；20 条壁刺材质与形态配方；6 条胶带制作和旧卷拼合配方。壁刺保留形态及第二材料状态，NeoForge 转换为 `minecraft:block_state`。
- 木颗粒增加压缩机 2→1 压缩木板，焦炉 1→1 木炭块粒及 25 mB 杂酚油，保留原版耗能与耗时。
- 原版黏土模具的烧制、压印、拆解表继续共用；仅在标签绑定完成后排除缺少实际材料的可选压印配方。附加模组提供匹配材料时仍可生效，不用错误材料填空。
- 13 种变速箱的物品模型采用共享、带 tint 的实体模型；放置后的动态齿轮／轴模型保留。修正 NeoForge 物品模型错误的 `model` 字段。
- 开孔枫树／彩虹原木补入现有“开孔原木”分类，REMI 总分类数仍为 450。

来源与授权见 [原版文件哈希](recipe-tag-source-20261018.json)。

## 建议人工复核

1. 在 1.21.1 查询黄蜂蜂箱、花盆、水银温度计、染料、砖燃烧室及含线缆配方，确认没有本次列出的空标签。
2. 中型青铜／黄铜轴、木头不再出现转换成矿石的配方。
3. 用黏土、刀、擀面杖制作空模，压印后分别用普通熔炉和高炉烧制，并确认成品保留模具形状；未烧制模具可拆回黏土。
4. 核对变速箱物品栏贴图和材料颜色、开孔枫树／彩虹原木折叠；检查新增机器、壁刺、胶带和木颗粒用途。
