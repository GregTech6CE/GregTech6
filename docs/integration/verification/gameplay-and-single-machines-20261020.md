# 2026-10-20 玩家反馈与单方块热交换器

本轮只处理提交的玩法反馈及单方块缺项，没有恢复已暂停的全面原版审计。两个平台共用业务目录、燃料计算及原生适配，不另建一套 NeoForge 玩法实现。

## 新增设备

原版 `Loader_MultiTileEntities` 707–717 行的八种单方块热交换器此前未注册；现已补齐。它们无需点火，使用 Hot Fuels 表，热量向上输出，冷却产物从正面排出，支持扳手、小型漏斗、龙头、排液器和放大镜。保留原版空载散热、输出背压、活动接触伤害、周围起火和 7/8 高度碰撞。正面允许水平或朝下。

| 材质 | 普通 HU/t | 致密 HU/t | 效率 | 原版 ID |
| --- | ---: | ---: | ---: | --- |
| 殷钢 | 16 | 64 | 100% | 9103、9153 |
| 钨 | 128 | 512 | 100% | 9107、9157 |
| 钨钢 | 128 | 512 | 90% | 9108、9158 |
| 碳化钽铪 | 256 | 1024 | 100% | 9109、9159 |

配方沿用原版 `PCP/OwO/PMP`；普通／强化机壳、铅板厚度、铜管粗细及铜／退火铜板要求分别保留。普通铜族板和管使用原版 ANY.Cu 范围。含材料数量由原版机壳 8U／26U、铅板 4U／16U及铜件准确组成。物品与世界模型共用原贴图，底层材质着色；普通和致密各有独立 EMI 折叠组，均进入原版热交换器创造分类和 JEI／EMI 热燃料工作站。

另补齐之前只实现 LV、MV 的磁通电机／发电机，新增 HV、EV、IV 共六台。参数来自原版 11023–11025、11113–11115；沿用已有旋转转换器、原版合成配方、动画模型、材料回收、着色和分类，LV、MV 数值保持。

对照原版 545 条显式单方块能源／机器注册，另行核对旧采集表未覆盖的原生注册。此项只表示声明和映射覆盖，不代表每台机器的完整行为已经验收；循环生成的目录及其它系统不纳入该数字。仍未找到对应实现的项目是魔法场吸收器，以及五档 BuildCraft Assembly Laser；后者需要相应兼容功能。详细源行、绑定方式和本轮新增项见同名 JSON。

## 同批反馈修正

| 反馈 | 处理结果 |
| --- | --- |
| 坩埚 Jade 只显示第一个物质 | 改为逐项传输材料、数量和相态，每项单独显示。 |
| 混凝土等 Jade 名称灰色 | 状态派生名称显式使用白色。 |
| 水桶／木桶查不到流体及空桶配方 | JEI／EMI 增加容器查询别名；装液木桶可查询对应空桶的制作方法，不改变真实流体配方执行条件。 |
| 机器界面流体无法用 EMI 搜索 | 基础机器、声明式机器界面提供鼠标下真实流体。其它独立界面未作为本轮完整验收范围。 |
| 气压计核心未合并 | 五种锅炉气压计加入独立 EMI 组，保留生成入口。 |
| 模具物品预览缺少刻形 | 修正物品多次渲染入口不再绕开刻形模型；实际客户端画面仍需人工核验。 |
| 固体燃烧室不能自动进料／出灰 | 两端增加燃料槽只进、灰槽只出的能力，保留正面限制。流化床也采用受限槽权限并阻止灰输出堵塞后继续消耗。 |
| 筛粉漏斗无法工作／从箱子取物 | 恢复两槽、内部材料余量、五种输出粒度、上方取物和下方输出；活动扳手切换粒度，钳子取物。按单件材料量结算，避免整组解析却只减一件。 |
| 空料斗／机器拆下后无法堆叠 | 空覆盖板存储不再制造无意义数据；普通机器移除运行状态，库存另行掉落。实际安装的覆盖板、模具刻形和便携储液容器内容仍保留。 |
| 建筑泡沫覆盖板名称相同 | 彩色泡沫、混凝土、沥青面板使用原版基础名称加颜色区分。 |
| 焦煤块热值与单个相同 | 提示读取实际燃料值；材料物品／方块接入原生熔炉燃料事件。9U 焦煤块为 28800 tick，单件 3200 tick；保留原版 32000 上限、原矿块 10U 特例和木板块／板条箱最低值，单块木板不再误用 2700。树皮按 100 tick/U，虚拟 unit 不作为实体燃料。 |
| “任意铁”只有杆生效 | 筛粉漏斗、打磨石、筛选台等源配方的板、双重板、螺丝、细导线也接受原版 ANY.Iron 范围；明确指定 MT.Iron 的配方不扩大。220 条生存配方生成核对通过。 |

原版榨汁机和搅拌盆在破坏时清除内部流体，已据此移除保液掉落。钢锭与胚料的原版手工无序转换已存在：2 钢锭换 3 胚料，及反向、批量配方，没有再增加重复配方。原版没有 `crushedPurifiedTiny` 的通用离心配方，因此没有凭普通大小配方推算新增；原版另有特定材料的干燥、浸洗及九合一转换。

## 192 L/t 锅炉、涡轮与蒸汽引擎

补充供汽设备为 192 L/t 蒸汽锅炉。原版 `MultiTileEntityBoilerTank:138–142` 在蒸汽缓存超过 75% 后以双倍额定值输送：这台锅炉此时可输出 **384 L/t**。殷钢涡轮额定最大连续输入是 192 L/t，单次灌入较多蒸汽也会形成过载；普通青铜涡轮上限更低，为 96 L/t。移植版现有锅炉与涡轮都保留这一原版规则。

Jade 新增锅炉当前可输送量，以及涡轮储汽、输入／输出范围和状态。机器过载爆炸强度按原版绝对能量包档位计算。高压脉冲可以导致过载，但原版通用过载爆炸／损坏默认均关闭；本批遗漏了这个配置默认值，后续已修正移植版错误开启的默认值及旧配置遗留，见 [过载默认值更正](overload-defaults-20261020.md)。没有存档的管道、压力和实际 tick 记录，不能断言高压就是其唯一原因。定向场景不等于完整洗矿生产链验收。

蒸汽引擎真实 KU 容量是额定输出的 2000 倍；原 Jade 曾按 1000 倍显示，造成半容量看似已满，现已修正。原版工作活塞即使朝向空气也消耗一个行程，低于工作压力的预热余量不会自动全部散尽；满压力继续超容量时停机排汽。其它旋转和液体燃料引擎已有空载消耗路径，柴油引擎 Jade 改为读取真实 RU。

## 验证边界

最终双版编译与六个隔离 NeoForge 场景全部通过（6m01s），详见同名 JSON：八种热交换器的真实能力／配方／热流体转换、上下箱子连接筛粉漏斗、原生熔炉焦煤块热值、额定持续供汽的青铜／殷钢涡轮实际向青铜洗矿厂输入 RU、192 L/t 锅炉在高压下实际输出 384 L/t、蒸汽引擎空载消耗及满压力超容量停机排汽。此前一次测试入口的模板命名空间写法错误已经修正；不是模组加载失败。
