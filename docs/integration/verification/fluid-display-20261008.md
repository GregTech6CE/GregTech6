## 实现

- 两端 `GTFluidType.describe` 优先读取现有明确的流体语言键，随后尝试原 `fluid.*` 键；材料名只作本地化后备。熔融铁、氧气等已有原版中文不再被通用英文模板或材料英文覆盖。物品与机器槽使用同一注册路径转换。
- 把两份各 243 行的混合猜测逻辑替换为一个不依赖 Minecraft 的共享规则及两个原生取值/组件适配器。温度、密度、发光、黏度读取实际 FluidStack 的 FluidType；不再用熔点、材料 RGB 或材料密度伪造流体属性。
- 等离子体优先、原生相态不一致提醒、实际锭可用性铸模提示、正/负/零密度、零光照/黏度省略，以及烹饪油/简单/导能/酸/魔法分类按源分支显示。现代 isLighterThanAir 与既有 FluidHazards、对照移植保持一致，不修改生产流体物理属性。
- 燃料值来自八种原生燃料表的流体索引与启用配方，取原第一流体输入对应的最大值；保留 U 精度至最后格式化，使用大整数避免溢出。不再用炉燃时间乘任意比例猜 GU/L。原润滑油的工业用途/不可燃提示优先并屏蔽燃料行。
- 绑定配方/罐内流体保留实际数量；普通未绑定创造图标不虚构 1000 L。外部模组流体也读取自身属性，所有权区分 GT6/原版/其它。创造无限填充提示放在客户端事件，仅在实际玩家有无限物品能力时出现；机器槽不显示这条提示。
- 原提示中的 32 条英文片段改为共享语言键。用户补丁没有相应译文，中文文件逐字回退原英文；未增加自拟中文、未修改 125676 个原键、未改变 8003 个已审定别名。现 139264 中文文件键/5585 英文回退；回退数增加来自原先藏在 Java 的英文显式进入门禁，不表示新增 32 个已汉化项。
