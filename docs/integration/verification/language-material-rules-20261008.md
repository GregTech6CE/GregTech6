## 采用与边界

- 按原 `LanguageHandler.getLocalName` 完整方法生成共享 `OriginalMaterialNameRules`，保留分支顺序、箱/块递归、166 个材料符号、322 个前缀的前后文字/相关标签、四材料组及四月一、二日命名。来源包括 MT、OP、ANY、CS、OreDictPrefix；原 GregTech-6 Team 的 LGPL-3.0-or-later 文件头保留，六文件 SHA 见回执。采用原版代码，因为它定义名称；不借其它移植版的通用拼接取代这些条件。
- 特殊材料同时匹配原编号和规范名。166 个符号中，160 个与当前身份导出匹配；六种 Actually Additions 水晶未在当前目录注册，规则保留但不宣称新增这些材料。Blaze/Clay 的命名成员由原工厂提取，不修改现有配方材料组。
