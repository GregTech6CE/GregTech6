# 战利品浏览器与本轮 NeoForge 反馈修正

代码目录 `C:/Dev/GregTech6`，原版只读来源 `C:/Dev/gregtech6-master/gregtech6-master`。本批是持续移植的一部分，剩余请求见 [反馈账本](neo-feedback-20261004.md)。本批机器回执完成后保存在 [JSON](loot-viewers-20261004.json)，来源作者、11 个原版文件 SHA256 和 5 个可选 EMI 依赖校验见 [来源记录](loot-viewers-source-20261004.json)。不推送本批提交。

## 变更

- 两版 JEI/EMI 各有独立战利品表和生物掉落分类。18 张当前 GT 表、1322 条实际解析战利品和 89 条生物规则；显示数量、单次加权概率、击杀/燃烧/幼体/抢夺等条件，完整说明保留在输出悬浮提示中。查的是 GT 自身表及 GT 向原版表增加的行，不是遍历所有其他模组/数据包的战利品。
- 原生 EMI 多方块结构、矿脉、小矿、岩层、基岩矿页面直接读取平台运行时目录；90/36/86/55/28 条。结构页显示实际控制器、部件数量和三维几何，并提供旋转、分层、复位和缩放按钮；这些信息页不参与合成树或可制作提示。JEI/EMI 共存时 GT 不再重复向桥接注册同一批配方。
- `core` 分享原版默认生物规则，平台使用真实 `LivingDropsEvent` 的 LOWEST 监听器。包括牛/马部位、狼/马肉、玩家击杀杂物、僵尸村民书、女巫战利品瓶、非玩家木石工具回收、箭/铁材质替换、肉品/肉屑和持久命名生物名牌；保留原物品数量和原生自定义数据。外部模组生物分支、斩首与完整食物效果仍待后续。
- 自动锤、自动点火器、USB/HDD 交换器按原版材料染色，NeoForge 物品使用不透明 ARGB。修正 Forge 通用装饰回调覆盖自动工具专用回调的问题；保留历史注册 ID，显示名称按正确材料修正。
- 机器、流体管、物品管、面板及物流盖板共用贴面绘制。基础层离宿主面 0.0005 方块，各纹理层再分隔 0.0001，避免深度闪烁；去掉原 1/16 方块厚度。坐标沿用服务端按钮映射，不改变互动位置。
- 恢复浸洗盆五片不锈钢板/锉刀/锤子原版配方；战利品板条箱恢复金箔/小齿轮/螺丝/弹簧/小外壳/空箱及三种工具配方。恢复真正的 `gregtech:crate` 普通木箱注册、原版木贴图、木板/螺丝/锯/螺丝刀配方及原版木材创造栏入口；螺丝标签含实际合法材料，条件缺席项为可选。
- 战利品箱撬开最多交付一堆随机候选战利品，并返还空箱；工具使用原版 return=500 的耐久换算。现代原版箱表候选选择并不等于 1.7.10 ChestGenHooks 的权重分布。

## 验证与范围

已有 `:core:check` 通过：2429 共享行为、7748 材料（含1212木材断言）、34 机器规格及53热学断言，共10264。没有新增完整 GameTest 扫描。

有限普通客户端创建隔离新世界，验证真实配方管理器、死亡事件总线、浏览器运行时与渲染。成功世界和失败尝试、日志 SHA、截图尺寸及 SHA 均保留于 JSON。三种新增配方使用装配好且可用的工具实际 `matches`/`assemble`；开箱检查仅验证返还注册身份与最多一堆边界，没有完整玩家撬箱交互记录。

每个平台检查 17 项真实生物事件、13 种变速箱模型及实际渲染层、61 个原版工具模型、6 种绳子、4 种过滤器、12 项自动工具/数据开关颜色；当前截图实际显示 61 个物品，包括两种箱子。样本没有未翻译物品名称；这并非所有通用标签与全部物品的语言审计。

双版 EMI 独立安装验证实际目录数量、牛蹄输出反查及五张实际配方页面；JEI 独立安装验证两个分类、实际运行时输出反查与两张页面。结构预览最初高度溢出，已减小视口并把按钮移回框内，当前截图确认布局。早期 Forge EMI 回执在空箱配方之前，不能用于声称三个新增配方或61物品图集已在该次运行通过；当前 Forge JEI 世界单独覆盖这些内容。

保留失败：未装配工具被实际合成逻辑拒绝（修正探针工具样本）、物品 ID 错误导致材料缺失（生产配方已修正）、空箱未注册（已恢复）、Forge 颜色覆盖（已修正）。失败的 Gradle 进程即使返回0，也不计为世界创建成功。

最后复核仅补充 en_us/zh_cn 的部位抢夺说明：普通动物每级5个百分点，亡灵马每级2.5个百分点。世界和页面截图在该两行文本澄清前完成；最终共享/平台class聚合校验与澄清前相同，语言文件与最终包另行核对，不重复世界行为检查。

EMI 开发模式日志仍有未翻译通用标签诊断；早期 Forge EMI 记录为81532个标签诊断与160条 EMI 内置酿造配方 ID 诊断。GT 新的信息配方使用 `/loot`、`/structure`、`/worldgen` 合成 ID，不能把整个日志称为无错误。新页面本身实际完成注册和查询；未把这些诊断隐藏。NeoForge 当前 EMI 重载51952毫秒，GT 插件406毫秒，尚不宣称解决所有整合包加载性能。

成品使用普通双版 assemble 打包、逐字节核对当前平台/共享 class、检查 ZIP CRC、元数据、Mixin 映射和测试类排除；成品标题页用已安装加载器库及 Java25 在 `C:/Dev/GregTech6` 内隔离实例启动。不会改整合包、启动库或原存档。成品启动、当前开发世界和完整生存/真实存档独立重载是不同证据，本批没有后两者或专服验收。盖板几何仅来源审查与编译，未声称已取得实际世界盖板截图。

本批最终成品路径及 SHA 以 JSON 的 `local_artifacts` 和完整成对的 `manifest.json` 为准。当前整体移植仍未完成。
