# 早期生存配方、石制工具与钢锤网络修复

范围：用户报告熔炉缺少起火器、木擀面杖与同材木浆缺失、陶瓷漏斗和浇筑件无法制造、普通石头名称错误，以及取得钢锤时网络断开。双版本沿用同一业务实现；开发版本保持 `0.0.0 / API 0`。本批不重新制作交付 JAR。

## 修复

- **熔炉点火原料**：原版 `craftingFirestarter` 不是仅打火石或火柴。炉中心改用共享标签，包含 14 个实际注册成员，恢复两种起火器、火焰弹、材质燧石点火器和有效打火机；空／损坏打火机仍不接受。
- **木擀面杖**：恢复原版的木板、任意两根木杆和锉刀／刀两条镜像配方。木杆可混用不同树种；擀面杖主体保留木板树种，柄按原版为 Wood。修复普通木材被工具等级筛除、原生配方预览原料为空的问题。
- **木浆**：将原版木材工厂隐式赋予的 `MORTAR` 规则补回工作性表及生成模板；原生木板／木杆可研钵磨浆。修正初始化顺序，在通用原版材料表加载之后绑定真实树种，避免又被覆盖成 Wood。原木、木梁、木板、楼梯和半砖的粉碎产物绑定真实树种及原版数量；肉桂树皮、枯木和压缩木的原版例外保留。关联锯切与车床输出也不再错误地统一为 Wood。
- **陶瓷链**：五种生坯器具共用纯 Java 目录，补 5 条普通炉、5 条高炉、5 条生坯回收、1 条反向浇筑道成形配方及 5 条 GT 炉烧制注册。既有漏斗、龙头烧制结果改为正式陶瓷变种。沿用原版黏土数量及工具损耗，不恢复已删除的旧测试身份。
- **普通岩石**：中文按原版 STONE 分支显示“黑色花岗岩岩石”等名称。新增模板的“岩石”后缀来自固定汉化补丁，保留所有原始整名键及汉化来源文件；含矿岩石仍保留含矿命名。石斧、锄、铲、镐、棍棒、锤的早期配方本已存在，本批通过实际配方管理器核验，不额外发明花岗岩刀配方。
- **钢锤报错**：用户附件为 1.21.1 创造槽位包编码失败，附魔键为 `minecraft:sharpness`。工具在客户端误用了集成服务端的动态附魔 Holder；键相同但注册对象不同，网络无法编码。改为按逻辑端选取当前连接／服务端注册表，并按注册键重绑定已标记工具的附魔；保留材料附魔、玩家等级和提示可见性。创造分类缓存也随附魔注册表切换，避免跨世界缓存旧对象。另在地牢铁砧和 Nexus 抽屉两个世界生成存储边界显式使用所在世界注册表，避免工作线程默认为客户端。

## 验证边界

双版主代码与探针编译通过；两个选定命名空间的 NeoForge 开发 GameTest 最终 7/7 通过（测试本身 1.060s）。新增语言模板完成原始来源投影，原始整名值修改数为 0。最终运行结果及日志摘要写入同名 JSON；不将编译等同于玩法通过。

定向案例覆盖实际配方的匹配／合成、树种与材料数量、研钵与粉碎产物、陶瓷成形和烧制／回收、18 种石制工具组合及含矿岩石负例；钢锤与燧石刀使用真实创造槽位包编解码，并用相同键但不同 Holder 的注册表重现和检查重绑定。

首次运行双版编译通过，选中的 5 项用例中 3 项通过、2 项木材用例失败，暴露了通用材料表的晚期覆盖，随后修正初始化顺序。钢锤探针借用其它命名空间的结构模板时被 NeoForge 命名空间过滤，首次未执行；改用自身结构模板后，最终日志明确包含该两项并通过，不把首次未执行记为通过。保留首次失败日志摘要与后续结果。

7 项通过后，最后补齐地牢／Nexus 两处工具存储边界，并单独完成最终双版编译（2m21s，通过）。这两处世界生成场景没有新增游戏运行，不能将前面的网络用例直接记为地牢或 Nexus 生成实测。

没有运行完整测试套件、Forge 游戏、客户端手动取物／查看器视觉、完整生存链、正式成品安装或真实存档重启。服务端网络编码用例通过也不能代替客户端人工复测。
