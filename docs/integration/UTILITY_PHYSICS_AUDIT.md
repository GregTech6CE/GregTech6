# 绳子物性与脚手架承托

2026-10-22，第101批，基线 `7556da56a`。继续[绳子脚手架核查](ROPE_SCAFFOLD_AUDIT.md)，新增 ALIGN-319～321，未调整玩法。14份原版、13份当前源码与14份平台视图，以及原作者／许可头和原生工件摘要见[回执](verification/utility-physics-audit-20261022.json)。正式记录累计321条，包含修复与保留政策，不是321个待修问题或完成百分比。

## ALIGN-319：三种绳子的可燃性未接入

原普通、草、藤蔓绳分别注册 `NBT_FLAMMABILITY=100`；丝、塑料、钢绳不设置该值。注册参数经 `MultiTileEntityRegistry`／class container、04基类读入，07基类保存该值并同时用于 `getFlammability` 和 `getFireSpreadSpeed`。原方块实际转发这两个查询，后续方向基类和绳子自身没有覆写它们，因此不是只有未消费的声明。

当前六种绳子都通过无可燃性覆写的 `RopeBlock` 注册。两版默认接口查询原生 `FireBlock` 的表，四个项目生产源码根下没有设置该表的具名调用。普通项目默认表下六绳均返回0，其中三种与原100不同；另外三种原本就是0，不能统称全部绳子都漏了可燃性。没有从羊毛地图色、羊毛声音或材质名称推断可燃性。

现有通用物品提示也会读取原生可燃性，补齐一个翻译键不能修复这条属性链。这里没有执行实际火焰传播、烧毁或提示画面；外部模组仍可能另外填充火焰表，不能用项目内未发现设置调用断言整个整合包永远为0。

## ALIGN-320：六种绳子的公开抗性值由1变成0.5

原六绳都注册硬度0.5、抗性1。07基类读取抗性，01基类在没有自身待执行爆炸时返回它；原方块的带世界上下文接口直接转发该值，没有经过另一层原生 `/5` 换算。这里限定普通新放置／默认参数，不包括自定义存档覆写或已经标记自身爆炸的情况。

当前 Forge 的基础绳及五变种工厂、Neo 的六绳循环都调用 `strength(0.5,0.5)`。已追两版属性方法、`BlockBehaviour` 构造字段赋值、`Block` 公共getter、平台上下文委托及 `ExplosionDamageCalculator` 的实际查询：公开块抗性为0.5，硬度名义参数仍为0.5。

查询值改变不等于“爆炸范围加倍”。原生计算还会结合流体抗性、射线、随机性、实体计算器等；本批没有运行实际爆炸，也没有推算摧毁概率或半径。当前通用提示直接复用公共getter，因此不能单改提示数字掩盖真实属性差异。

## ALIGN-321：脚手架的承托面与原版不一致

原 `isSideSolid2`、表面实体／不透明／可挂接声明均为“顶面，或设计3”。06基类会将无覆盖板时的这项结果转给实际方块。原顶面火把查询在没有专用覆写时也回退到这个顶面判断。

当前脚手架有完整选中轮廓，但没有单独的 `getBlockSupportShape`。原生支撑形状实际来自空实体上下文的碰撞形状；`dynamicShape` 已开启，查询不会被误读成固定缓存。已继续追 `CollisionContext.empty`、空实体字段、FULL／CENTER判定和两版顶部／墙面火把消费者。

| 状态／查询 | 原版，无覆盖板 | 当前支撑形状 |
| --- | --- | --- |
| 设计0，顶部 | 支持 | 支持 |
| 设计1，顶部 | 支持 | 支持，空实体上下文包含顶层台面 |
| 设计2，顶部FULL／CENTER | 支持 | 拒绝，中间没有台面 |
| 设计1／2，实际侧框外侧FULL | 拒绝 | 支持，侧框墙覆盖完整方块边界面 |
| 设计3，全部面 | 支持 | 支持 |

按四种实际侧框方向、四种设计、六面FULL及顶部CENTER，共112项轴对齐面覆盖源码推导，其中16项不同（FULL十二项、顶部CENTER四项）。比较按实际墙面归一，不直接套用旧／新朝向枚举。没有调用 `VoxelShape` API、放火把或触发真实邻格更新，不能把这张有限表当作所有挂接模组都已验收。

覆盖板碰撞Mixin虽在两平台配置中启用，但脚手架没有覆盖板实体宿主；这也不能用来替代它缺少的专门支撑合同。未来对齐需要分别处理选中、移动碰撞和挂接支撑，不能只把轮廓改成完整方块。

## 已有对应与范围

原60行金属目录与当前 `GTStorageMetals` 按声明顺序比较，脚手架硬度参数都为5、各行抗性参数相同；两平台注册也都实际消费该抗性。没有把原通用金属目录中的另一硬度值误当成脚手架自己的硬度。记录中保留旧材料符号与当前材质引用；该数值比较不替代所有材料别名、ANY组范围、采掘速度或最终爆炸行为验收。

原生证据来自两个本地工件的25个条目。14份Forge只读反汇编输出中5份复用旧批、9份在本批取得；Neo引用11份源码条目。工件／条目／完整反汇编按原始字节校验，引用片段仅统一CRLF再核对；没有初始化目标类。
