## 建议核验

- 创造机械页不再夹杂两类压模模具；万能花盆上方 GT 树苗透明区域不再出现实色背景。
- 同材料板对板堆普通／潜行右击均增加数量；旧错误覆盖板撬掉最后一片后，客户端也立即消失，重进世界不复现。
- 新生成的高处主世界地形不再出现上述八种原版矿；新地牢刷怪塔源水会自然流动；基岩矿房深板岩矿石顶面贴图与周围完整深板岩端面匹配。
- 手钻可在普通／小型矿石埋炸药；对基岩矿石拒绝，物品／能量不因失败丢失。
