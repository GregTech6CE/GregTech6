## 本轮已收集、尚未并入正式主表的工具证据

本轮从 409a6aac6 开始，检查起火器／打火机／灭火喷罐。下述五组证据还需要恢复后整理引用、来源哈希与正式编号，不计入上述 126 项：

- 原版 Behavior_FlintAndTinder 的易燃增强分支失败后仍可能进入普通概率分支；默认理论概率为 65% + 35% × 30% = 75.5%，当前单次增强判定为 65%。普通材料默认 30%、低耐久材料 100% 两种基础结果一致。已有 ALIGN-006 的 BURNING 缺口另计。
- 原版 Behavior_Lighter 的一次性 useUp 受无限物品资格保护，当前 singleUse 成功有成本／失败分支都无创造模式消耗豁免。多次使用形态的 consumeFuel 已有豁免，不能扩展为全部打火机消耗错误。
- 原版两种点火物品使用 onLeftClickEntity 拦截；当前多物品经 interactLivingEntity，GTToolItem 起火器经 hurtEnemy。直接调用辅助函数的旧 GameTest 不证明真实回调一致。完整攻击伤害与双端同步仍未运行验证。
- 原版固体／液体／流化床燃烧室实现点火及灭火工具钩子。当前 Forge 两种共享燃烧室实体未实现 ItemBehaviors.Ignitable；Neo 有手动点火适配；两版均未接 Extinguishable。已有原版打火石和 PoweredToolTarget 路径不能代替喷罐／随机工具的分派。
- 原版 IBlockToolable.Util 根据目标是否支持工具接口选择原生或 ToolCompat；当前点火辅助函数在原生返回 0 后仍尝试 TNT／世界火回退。已点燃炸药的 onIgnite 返回 0，是一个可继续核验的具体目标。未在游戏中复现该场景。
