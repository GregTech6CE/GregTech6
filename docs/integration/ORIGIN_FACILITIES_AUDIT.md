## 两个完整方法体的核对结果

`WorldgenNexus.generate` 与 `SourceNexus.generate` 在列明适配后，全部 4883 个有序代码 token 一致。适配仅包括 WD.set 委托、两个地基填充起点改为 `world.minY()+1`、旧全局 RNGSUS 改为传入 Random。后一个改动不意味着关闭道路时随机石材输出与旧版逐次相同；当前用户要求道路默认开启，不能据此把未运行分支删掉。

`WorldgenTesting.generate` 与 `SourceTesting.generate` 在列明适配后，全部 2193 个有序代码 token 一致。适配为世界上下限、六向半砖数组、方块／覆盖板委托，以及将库存表达式独立为不可变表。原版 49 次设施放置保留 48 次，唯一省略的是用户明确要求删除的支持者证书 32764；这不是漏移植。

原版工具箱的 144 个物品表达式与 `OriginTestInventory.ROWS` 按槽位逐字一致，含数量、材料名称、工具等级和充能表达式。这里证明的是源记录保留；原生解析后实际材料、附魔、充能、功能和模型仍须独立核验，不能把表达式相同等同于物品功能全部相同。

原版构造器、enabled／CFG 方法不在上述方法体等价范围内。当前模块全开是用户选择，CFG 仍留后续。

## 实际共享代码短探针

只编译并运行五个实际 core 源文件及记录器，约 0.77 秒；没有原生 Feature、Minecraft 世界或整个模组初始化。

- Nexus 在正确锚点接受，错误锚点拒绝；记录 50510 次有效块写入请求，Y 为 −63…129，出生点为 `(0,71,0)`。
- 四个测试房区块均接受，记录 394867 次有效块写入请求，Y 为 −63…319。次数包含覆盖同一位置的请求，不是不同方块数量。
- 全部 48 次设施请求的坐标、旧 ID 和参数文本，与原版去掉证书后的顺序逐项一致。
- 保留一条排液覆盖板请求 `(36,62,-17)`，侧面 3；库存表实际长度 144。

记录器只裁剪区块／高度、计数和接收请求，读取返回空气；这些数字不是游戏中真实改写量、自然生成密度或地形完整性证据。探针代码、所有命令和输出随回执保存。

## 原生适配边界

48 条请求涉及的 25 个旧设施 ID 均有 `NativeOriginFacilities.block` 映射，没有因为同一设施重复出现而重复计种类。这是映射覆盖核对，未重新执行原生注册表或实体创建。

已追到实际消费者：朝向文本映射到存在的 facing 属性；八段管道的连接文本映射到方向属性，管道实际按这些属性查询连接；预装库存写入四联抽屉的 items，当前容量常量为 144。磨石预装次数、ZPM 初始电量和按钮反转也有各自委托。是否能在原生生成、保存／重启和客户端更新后保留，仍需后续实测。

既有 `OriginFeedbackChecks` 会检查注册、部分设施和库存，但其 expected 也调用同一个 `NativeOriginItems.stack`。因此旧检查源和旧通过记录不能独立证明解析器完全遵循原版材料、数量、充能和附魔语义；本批没有把它当成新的游戏通过记录。
