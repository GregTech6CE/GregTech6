## 第一轮：最近修改，优先验收

### A. EMI 工具头用途：issue #27

**环境：先用 EMI，暂不加 JEI，确认原生 EMI 页面自己就能工作。** 折叠扩展不是这项功能的前提。

- [ ] 在 EMI 搜索两三种确实存在的工具头，至少包括一种非钢材质和两种工具类型。打开工具头的“用途”（按你当前键位设置操作），应能找到装配成工具的页面，而不只是工具头自身的制作配方。
- [ ] 核对页面输入的工具头材质、类型和输出工具一致；不能点击铜工具头却只出现钢工具头装配。
- [ ] 查看柄槽允许的候选，挑一个实际合成，再换一个不允许的柄作对照。显示允许的组合应能在工作台合成，不允许的组合不应被误列为合法候选。
- [ ] 若页面含加工工具，实际合成时核对工具的保留／磨损，与普通材料消耗区分开。
- [ ] 加装 JEI 后重复一次：同一工具装配行不应因桥接重复出现。若你使用独立 JEI，也抽查原装配页仍可用。

当前页面输出用代表性柄展示，未启用自动配方树；“没有一键自动合成”不属于本次 #27 的失败判据。重点是**所有合法工具头能查到装配用途，候选柄与实际合成相符**。

### B. 材料形态折叠：issue #28

**环境：EMI + 对应游戏版本的 Reliable EMI。** 只有普通 EMI 时，列表保持原样是预期行为。

- [ ] 找到锭、板、杆三个组并展开：铜锭、铁锭等应在锭组，铜板、铁板等应在板组，各种材质的杆在杆组。
- [ ] 不应出现把“铜锭、铜板、铜杆”合并成一个铜材料组的情况。
- [ ] 抽查粉、小粉、粒、齿轮等其它已接入形态，组名和内容对应。小粉与粉、长杆与杆等不同前缀保留各自分组。
- [ ] 工具、机器、玻璃、木板、半砖、模具不应被本次新增规则归入材料组；特别检查防腐木板没有进入板组。其它模组或你已有配置自己建立的组需单独辨别。
- [ ] 折叠、展开后搜索一个具体材料物品，并查看其配方和用途，物品应仍可找到和使用。
- [ ] 切换简体中文／英语，组名应正常显示，不能露出 `itemGroup.gregtech.*` 键名。组名沿用既有翻译，不要求此次新增翻译。
- [ ] 退出并重新进入世界，确认分组恢复正常；观察 EMI 是否完成加载，而不是长期停在 `Baking recipes` / `EMI Reloading`。

共定义 56 个材料形态组，但实际可见组数受注册物品、非空标签、隐藏设置和扩展配置影响，**不把必须显示 56 个按钮作为通过条件**。

### C. 新增半砖的九宫格与实际放置

**样本：建筑泡沫半砖、发光玻璃半砖，各取两种颜色；再取一种石材半砖作对照。**

- [ ] 手持上述半砖瞄准可放置方块，九宫格应显示；不同颜色不能漏掉。
- [ ] 分别点击面中心、边缘、角落，并换顶部、底部和侧面测试。实际放置方向应遵循同类石材半砖的九宫格规则。
- [ ] 主手为空、副手拿半砖时检查显示；两只手均持物时检查主手优先规则，预览应与实际使用物品一致。
- [ ] 放下后从不同方向查看，排查方向错误、缺面、闪烁以及颜色丢失；发光玻璃顺带查看相邻半砖透视。

蓝云杉木半砖仍是原生上／下／双层半砖，不具备这套六向放置，不能因没有九宫格就算此项修复失败。

### D. 排水盖板

**准备：能接收相应流体、容量充足的储罐及排水盖板。先清空储罐，避免原有流体造成误判。**

- [ ] 对着含水半砖等实体方块运行，实体方块不应被排水盖板整块删除。
- [ ] 分别抽取 GT 河水、海水、沼泽水：产物应分别为普通水、海水、脏水；世界中的 GT 大水源应保留，容量足够时单次最多接收 16000 mB。
- [ ] 换普通有限水源测试；它不应被当作上述 GT 持续大水源，同样核对容量不足时的行为。
- [ ] 对 GT 大水源抽查流水及不同安装方向，不能仅因它不是源头方块就完全失效。
- [ ] 雨天检查露天收雨，再搭屋顶／挡住收集方向作对照。遮挡条件下应停止对应收集；侧面安装时额外核对收集点下方支撑的影响。

OpenBlocks 玩家经验抽取、其它模组特有史莱姆和全部外部容器兼容尚未完整实现，不以这一轮通过宣称跨模组兼容已完成。

### E. 覆盖板厚度与太阳能板

- [ ] 在完整机器表面装盖板，应贴合机器面，不向外悬浮一像素。
- [ ] 在细管道／线缆这类非完整宿主上装盖板，从正面、侧面、背面查看：应有两像素厚度、侧面、背面和支撑，几何保持在方块边界内。
- [ ] 抽查泵、输送机、机械臂的内外贴图，以及有颜色的材料板／面板；安装六面时不应缺面、方向反转或丢色。
- [ ] 在符合安装条件的绝缘信号线上检查火把和中继器：应使用细柱外形，切换信号后亮灭贴图正确。
- [ ] 用水桶尝试向太阳能板灌水、对其抽水，并检查水边／水中放置行为：不能出现含水太阳能板、重复取水或崩溃。顺带确认正常放置时朝向和发电状态未受影响。

### F. 一次保存与重进

- [ ] 保留刚才放置的盖板、半砖、太阳能板以及装有流体的储罐，保存退出后完全重启游戏再进入，核对方向、颜色、盖板设置和流体存量。
- [ ] 确认两个版本均能启动、创建世界、打开 EMI 并正常保存退出。出现异常时保留当次完整日志。

这只验证本次样本，不等于所有机器或所有旧存档已经通过兼容验收。
