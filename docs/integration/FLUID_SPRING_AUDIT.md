## 已有实现和明确取舍

七种固定流体／间隔变体、两端实体类型注册、活动状态保存、客户端模型数据和流体tint已有。八套blockstate／item资源都通往实际iconsets叠层模型；旧decoration原型不在这条路径，不能据它的金属纹理误报全部缺图。普通放置和直接emit路径存在；现有测试直接调emit，不能证明真实tick启动合同已对齐。原泉并非可直接抽取储罐，未因当前没有可抽罐而报缺。

amount在此是随机roll边界，不是每次排出该数量的流体或储罐容量。原非正数回退600，当前夹到1；原未配置泉默认普通水／1，当前旧载体无fluid字段时无输出；识别到旧流体后会归一到固定变体间隔，例如旧lava／500变为1000。这些缺省／迁移政策已记录，本批不改变。扁平化本身来自用户要求，不借审计把正常变体退回NBT身份。
