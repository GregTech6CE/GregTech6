# 集成、来源与验证结论

本目录保存跨平台、跨模组与原 GT6 对照的长期结论，包括来源版本、单位转换、兼容条件、可复现问题及覆盖状态。目前只有模板，尚无正式报告。

新报告复制[验证结论模板](report-template.md)，命名 `<topic>.md` 或 `<platform>-<topic>.md`，并在下方添加链接。同一主题持续更新原报告；结论与证据要求见[验证与验收](../development/validation/README.md#结果与证据)，其他材料按[文档归属](../development/repository-layout.md#文档归属)存放。
