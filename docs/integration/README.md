# 集成、来源与验证结论

本目录保存跨平台、跨模组、原 GT6 对照与移植验证的长期结论。首次修改先读[架构](../architecture/README.md)与[验证规范](../development/validation.md)，再使用[结论模板](report-template.md)。

适合保存：原始实现的仓库/版本/路径、数据单位转换、两平台已知差异、可选集成兼容条件、可复现问题与覆盖状态。职责归属放架构文档；发布执行记录放 [operations](../operations/README.md)。

新报告建议命名 `<topic>.md` 或 `<platform>-<topic>.md`，明确范围和状态；持续同一主题优先更新原报告。全文日志、下载源码、反编译文件、截图原件和个人计划放 `work/<任务名>/`，不要直接搬入本目录。局部验证未完成时写“未验证”，不写成移植完成或全面一致。

本入口建立归档方法，不表示已经存在兼容性验证结论。新增正式报告后在下方目录中添加链接。
