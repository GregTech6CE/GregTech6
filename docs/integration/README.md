# 跨模组兼容与联动

本目录记录本模组与其他模组之间的兼容与联动结论，重点覆盖联动内容、联动材料、联动配方、交互/资源冲突与处理方式。

系统设计、偏离原 GT6 的有意取舍以及双平台间的长期实现差异，请查阅并归入[长期决策](../decisions/README.md)；一次性本地探查、完整日志与临时计划应放入仓库根目录 `work/`，不留在版本库文档中。

新增报告时请复制[兼容报告模板](report-template.md)，以 `<modid>.md` 或 `<modid>-<topic>.md` 命名，并在下方目录添加链接；同一联动主题应持续更新原文档。结论表述与证据要求见[验证与验收](../development/validation/README.md#结果与证据)，其余材料存放规则见[文档归属](../development/repository-layout.md#文档归属)。
