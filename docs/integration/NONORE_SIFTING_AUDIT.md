# Bounded source-NO Sifting alignment

## Source rule and repaired boundary

Paired original sources register the Sifting pair only when both purified whole/tiny forms and a common gem actually exist. The recipe listener does not itself forbid a material merely because source ORES generation is absent. Therefore the repair suppresses only loader-owned fabricated builtin inputs, reusing the existing reviewed source-NO profile and exact-identity dormant ledger. Supported startup form requests and external inputs keep their existing conservative deferral/activation paths. Other-owned same-input winners are never removed. No signature sweep or item-ID deletion is used.

The observed source-NO Sifting candidates are Flint8002, Ice9802 and Obsidian8214, each whole/tiny. In controlled paired source, Flint disables own gem generation and the itemFlint/unprefixed composition path does not register gemFlint; Obsidian has no builtin common gem. Their externally deferred port continuation behavior remains conservative UNKNOWN, not a claim of original positive recipe parity.

Ice explicitly forces common/flawed/chipped gems but lacks the CRYSTAL prerequisite for upper legendary/exquisite/flawless generation. With actual inputs/common gem and no supported external upper-grade override, output counts are **8/4/2/1/2/4/1**, the final slot dust. With accepted startup upper-grade requests, those first three slots are corresponding grade stacks **1/1/1**. Existing upper-grade item IDs remain registered for saves; absence of source generation intent is not permission to delete them.

## Ownership and supported lifecycle

Only the two owned Sifter calls capture immutable startup definitions. Exact accepted Recipe handles are tracked; a rejected insertion never owns the incumbent. Rebuild removes only those exact owned objects, processes supported external input bindings/continuations, then retains existing final datapack priority. Startup accepted grade requests/explicit bindings are resolved before source fallback. The actual Ice profiles use supported rawOreChunk/crushed tags to activate port continuations; this is not a claim that an original raw chunk alone generated both missing purified forms.

Late grade tags can be recognized as crafting aliases without being stored material-grade output bindings. This patch does not add late grade-tag Sifter output rebinding, public composition mutation, or arbitrary late addon callback redispatch. Existing immutable startup definition semantics are retained. No same-JVM second-world transition is inferred from separate loader runs.
