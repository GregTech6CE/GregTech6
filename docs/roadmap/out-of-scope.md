# 否决提案

本文档记录在路线图与机制讨论中**明确否决**或**划出本体范围**的设计方向，避免后续讨论反复拉扯同一批已裁决议题。

> **边界说明**：列入本清单不代表“绝对不能作为第三方或独立附属存在”，而是明确**不进入 GT6CE 本体主线**；若未来社区有强需求，须经正式 RFC 重新评估。

---

## 一、明确否决的机制与设计方向

### 1. GT5 式高电压数值膨胀与“扣 0”倍率堆叠
- **否决内容**：沿用 GT5 的 `LV ~ LuV` 电压阶梯划分科技阶段，或靠单机时间减半/产出翻倍的纯数值“扣 0”膨胀来拉长流程。
- **原因**：违背 GT6CE **多能量相互支持**的特色主线，会把热力学、配比与物流决策短路成单纯的“电压叠叠乐”。

### 2. 燃烧室机器属性上的最高温度上限与分级
- **否决内容**：在燃烧室/热源机器的属性层增加最高温度上限（如限制特定材质燃烧室最高只能烧到多少度）或热量单向传导属性体系。
- **原因**：高温门槛应做在**具体配方**层，而不是把限制强加在燃烧室自身属性上。

### 3. 用 GUI 全面取代世界内实体交互
- **否决内容**：取消或边缘化世界内用扳手/螺丝刀/手持物品直接交互的设计，改为所有机器与覆盖板都必须通过打开 GUI 操作。
- **原因**：违背“空间里的工坊，而非菜单里的进度条”这一核心特色；可选二级配置 GUI 只能作为复杂覆盖板的辅助入口，世界内交互仍是一等入口。


### 4. 多方块“换壳就地数值升级”
- **否决内容**：通过直接替换同构型多方块的高阶外壳（Tier Casing）来就地拉高机器转速、并行度或产出倍率。
- **原因**：属于变相的数值套娃与膨胀，无法带来新的工艺决策或自动化变化。


### 5. 纯粹堆倍率的“大型版”机器
- **否决内容**：仅仅为了拉高倍率而将单方块机器直接做成“64 倍速大型版”，却不引入任何新机制、副产分支或能量谜题。
- **原因**：属于“数值正确 = 设计正确”的机械膨胀，大型多方块应服务于能量协同谜题或提供独特机制奖励。

## 二、明确不纳入本体的跨界与边缘内容

- **星系、简易航天与外星维度**：多维度火箭发射、太空站、星系行星与外星矿脉等跨界航天扩展（交由附属或联动承接）。
- **食物与农业烹饪**：原各类食物、饮料、罐头食品、三明治与扩展农作物/榨汁系统（迁出为独立附属）。
- **枪械与弹药**：枪械与子弹/箭头等投射物系统（迁出为独立附属，本体仅保留通用机械零件）。
- **药水流体酿造**：94 条药水流体、药水机器配方及毒瓶/毒性木桶（已移除，回归原版药水体系）。
- **食物五项隐藏营养统计**：缺乏反馈的酒精、咖啡因、脱水、糖、脂肪隐藏统计与关联伤害类型（已移除）。
- **硬币系统**：`coin` 前缀硬币物品、硬币堆与铸币模具（已移除，地下遗迹改由锭堆承接）。
- **养蜂系统**：蜜蜂、蜂窝、蜂房与蜜蜂分析仪（计划移除，工业蜡由原版蜜脾或石化/植物蜡替代）。
