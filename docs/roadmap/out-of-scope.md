# 否决提案

本文档记录在路线图与机制讨论中**明确否决**或**划出本体范围**的设计方向，避免后续协作反复拉扯已裁决议题。

> **边界说明**：列入本清单不代表“不可作为第三方或独立附属存在”，而是明确**不纳入 GT6CE 本体主线**；若未来社区确有强需求，须通过正式 RFC 重新评估。

---

## 一、明确否决的机制与设计方向

### 1. GT5 式高电压数值膨胀与“扣 0”倍率堆叠
- **否决内容**：沿用 GT5 的 `LV ~ LuV` 纯电压阶梯切割科技阶段，或单纯靠“单机耗时减半、产出翻倍”的数值膨胀拉长游戏流程。
- **原因**：违背 GT6CE **多能量协同**的核心立意，会将热力学调控、化学配比与物理物流简化为单调的“电压叠叠乐”。

### 2. 燃烧室机器属性上的最高温度上限与分级
- **否决内容**：在燃烧室或热源机器自身属性中增设最高温度上限（如限制某材质燃烧室最高只能烧到固定温度）或单向温度梯度限制。
- **原因**：高温工艺门槛应体现在**具体配方**与散热平衡上，而非强行给燃烧室机器属性加设人为封顶。

### 3. 用 GUI 全面取代世界内实体交互
- **否决内容**：取消或弱化扳手、螺丝刀与手持物品的世界内直接交互，改为所有机器、模具、砧与覆盖板均须打开 GUI 操作。
- **原因**：违背“空间里的工坊，而非菜单里的进度条”这一核心特色；复杂覆盖板的可选二级配置 GUI 仅作为辅助入口，世界内实体交互始终是一等公民。

### 4. 多方块“换壳就地数值升级”
- **否决内容**：仅靠替换同构型多方块的更高阶外壳（Tier Casing），就地拉高机器转速、并行度或产出倍率。
- **原因**：本质是变相的数值套娃，无法带来新的工艺拓扑或自动化设计挑战（多方块进阶应通过功能模块扩展或能量协同谜题实现）。

### 5. 纯粹堆倍率的“大型版”单方块机器
- **否决内容**：不引入任何新机制、副产支线或多能量协同要求，仅将单方块机器直接放大为“64 倍速大型多方块”。
- **原因**：属于“数值膨胀替代机制设计”；大型多方块设施须服务于多能量协同谜题、连续化工拓扑或规模化专属工艺。

## 二、明确不纳入本体的跨界与边缘内容

- **星系、简易航天与外星维度**：火箭发射、空间站、星系行星与外星矿脉等跨界航天内容（交由独立附属或外部联动承接）。
- **食物与农业烹饪**：原版 GT6 的各类食物、饮料、罐头食品、三明治方块与扩展农作物/榨汁系统（于 `v1.1` 迁出为独立附属）。
- **枪械与弹药**：枪械及子弹、箭头等投射物系统（于 `v1.1` 迁出为独立附属，本体仅保留弹丸 `round` 与螺栓 `bolt` 等通用机械零件）。
- **药水流体与机器酿造**：94 条药水流体、490 条药水机器配方及毒瓶/毒性木桶（已于 `v1.0` 移除，全面回归原版药水体系）。
- **食物五项隐藏营养统计**：缺乏界面反馈的酒精、咖啡因、脱水、糖、脂肪五项隐藏统计与关联伤害类型（已于 `v1.0` 移除）。
- **硬币系统**：`coin` 前缀硬币物品、硬币堆与铸币模具（已于 `v1.0` 移除，地下遗迹改由金属锭堆承接）。
- **养蜂系统**：蜜蜂、蜂巢方块、蜂窝物品、蜂箱与膜翅目昆虫分析仪（于 `v1.1` 补齐工业蜡替代来源后整体移除）。
