# GT6CE v1.0 路线图

## 方针

- **非侵入式**：不删除或替换其他模组的配方、世界生成、方块与物品，不通过加载顺序或全局事件改写他人内容。
- **奥卡姆剃刀**：不做无意义的内容和玩法。优先使用原版或联动模组本身的内容。
- **自洽性**：材料、配方、进度与世界生成形成闭环。未安装联动时本体完整可玩。
- **联动附属化**：可选玩法、联动兼容与非核心系统移出本体，本体只保留核心玩法与基础内容。
- **可配置**：尽可能使用可配置项来提供不同的游戏体验。

## 架构

- **API**：包含接入接口、系统运行规则。
- **本体**：包含核心玩法与基础内容。
- **附属**：包含联动兼容、非核心玩法与可选内容。

## 路线图

- **1.0**：发布
- **1.1**：API 稳定，汉化项目迁移且稳定，CI 诊断与构建稳定
- **1.2**：无缺陷，基本自洽，联动附属化
- **1.3**：首个小内容更新
- **2.0**：首个大内容更新

## 项目管理

- **汇报问题**：写清问题、复现步骤、预期结果与实际结果，并附上相关日志。
- **提交建议**：描述立意、修改内容，确认提议符合设计准则。
- **PR**：说明立意、修改内容和范围、实际测试结果。
- **RFC**：重大更改需要先建立 RFC issue，公开讨论并经维护者合议后决定，通过 RFC PR 合入。
- **文档管理**：遵循项目内已有的规范，将应该记录的事项记录在规定位置。
- **行为差异**：与 GT6 的行为差异需要记录原始行为、差异、原因与影响。
- **可更改性**：方针与路线图不是固定的，社区可以通过 RFC 讨论、维护者合议后修改。
